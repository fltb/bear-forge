# 玩家受限模拟接口

状态：设计提案，尚未实现。该服务在策略/会话适配层，不增加内核 opcode。与设计实验的真实状态分叉接口隔离。

执行颗粒度以 [当前执行契约](runtime-contract.md) 为准：仅支持的决策等待边界可分叉；可恢复预算暂停为后端可选能力。

## 1. 核心权限

玩家搜索从其合法信息状态 I 建立假设世界，不从真实隐藏世界 S 分叉。I 包括实际收到的观察、允许保留的历史、公开规则版本以及明确授权的信息，不包括真实随机种子、对手私有状态或未公开控制帧。ticket 仅用于授权和关联，不作为采样种子/特征。

对于相同 I、相同公开先验/服务配置的任意两个真实世界 S1、S2，受限模拟的可见响应分布必须相同。固定同一规划随机输入后，响应应相同。此条件也覆盖错误、候选动作、请求次数限制和返回元数据；墙钟侧信道需通过运行隔离、计时策略另行控制，不声称已经形式化解决。

## 2. 谁提供什么

- 游戏包提供 PlanningContract：合法历史编码、信息约束、假设世界构造、有效性检查、从游戏规则边界建立执行 context 的流程。
- 策略层选择已批准且版本化的先验/对手模型，可维护由自身合法历史更新的信念。
- 规划服务维护采样随机流、假设世界、内核实例、模拟对手执行和预算。
- 内核只执行游戏程序及分叉假设 context，不知道“信念”或“玩家搜索”。

假设生成不是通用内核自动完成的工作。每个游戏可采用粒子历史、约束求解、重建后重放或游戏专属初始化器。需重建相关历史、待处理流程、延迟任务和随机状态，不能只填补手牌字段。没有正确生成器的游戏可以先接无搜索策略，不假装支持完整搜索。

世界应满足已知事实与声明的游戏约束。约束一致不等于采样概率正确：均匀分配未知牌不等于对手经过构筑/选牌后的后验；先验版本及近似必须记录。构造失败或预算不足是 planning unavailable，不是推断真实世界不存在该动作的证据。

## 3. 概念接口

```typescript
interface Planner {
  open(ticket: DecisionTicket, options: PlanningOptions): Promise<SearchSession>;
  sample(session: SearchSession, count: number): Promise<WorldHandle[]>;
  fork(world: WorldHandle): Promise<WorldHandle>;
  advance(world: WorldHandle, action: Action): Promise<SimResult>;
  close(session: SearchSession): Promise<void>;
}

type SimResult =
  | { kind: "decision"; world: WorldHandle; observation: SimObservation }
  | { kind: "terminal"; world: WorldHandle; outcome: SimOutcome }
  | { kind: "yielded"; world: WorldHandle } // 可选：仅后端支持可恢复暂停时
  | { kind: "unavailable"; reason: PublicPlanningReason };
```

open 不接受真实 SnapshotRef 或任意 world 查询代码。规划选项仅允许预算、已批准先验/对手模型版本等。内部获取冻结的合法信息状态；服务进程运行时只接收 I，不挂载真实对局 context。

advance 校验分支和当前决策，提交搜索者动作，然后在假设世界中按游戏规则推进：遇到对手决策，由服务调用对手模型，它只获得该对手在该假设世界中的合法观察；返回搜索者下一选择、允许公开的终局或预算暂停。任意原生对手回调不能因此获得隐藏状态权限。控制他人、多人等采用游戏定义的决策授权，不能简单以角色 ID 判断。

WorldHandle 是不可读取的随机不透明句柄，不能由牌序、对象地址或状态哈希生成可探测信息。分支与真实行动 ticket 分开，不允许模拟动作提交进真实对局。SimObservation 与实际观察显式区分，不得写回真实玩家历史。

## 4. 三种随机性与恢复

真实游戏随机流、假设世界采样流、假设世界未来随机流分开管理。规划随机输入可保存以复现，绝不从真实未知牌序/真实 seed 推导。已知牌序约束保持；未知部分按声明先验采样。假设 fork 保留其随机现场，可用于配对比较；策略分歧可能改变随机调用，不能宣称总能同随机数对齐。

不必从开局重放真实游戏来建立搜索。游戏可从完整的合法信息状态构造假设执行现场；当只能通过历史保证约束时，假设历史的重放是允许的构造方法，与内核分叉依靠重放是两回事。首版只在游戏声明可重建的决策边界开放规划。

## 5. 防止搜索虚假优势

不向策略直接返回采样的全部隐藏字段。多粒子搜索遇到同一合法信息历史时，后续选择应按该信息历史共享/聚合，不能按粒子 ID 各自挑“知道对手牌”的最优行动再平均。模拟对手亦只能使用自己的观察。

隐藏状态采样只来自 I 时，知道某个假设不等于知道真实秘密，但会导致策略融合等规划偏差，因此此限制既保护接口，也提高估值可信度。搜索估值仍依赖先验、对手模型和截断评价；不是最优性证明。

## 6. 预算与验收

预算至少计假设生成工作、假设数量、决策推进次数、模型调用/搜索扩展与墙钟截止；后端支持时可增加内部指令计量。只限制 rollout 数不足以限制复杂连锁。耗尽返回 unavailable；仅后端支持安全可恢复暂停时可返回 yielded。中断后无法续跑的分支废弃，可从之前的有效快照重试，不判游戏失败或平局。

验收：成对改变真实隐藏状态且保持 I 不变，固定规划随机输入后返回一致；模拟不会改动真实 context/历史；对手模型拿不到搜索者私有牌；恢复分支一致；信息等价节点不因粒子 ID 选择不同动作；过期 ticket/越权句柄被拒绝。

首次实现先支持一个游戏明确的规划边界、固定脚本对手及有限深度模拟。完整游戏搜索支持范围逐项声明。全状态设计干预使用独立 Analysis 权限和接口，不复用玩家 Planner 的受限凭证。
