# 当前执行与实验边界

状态：2026-10-08 最新需求契约，未实现。涉及执行颗粒度、实例模型及后端选型时，本文件优先于旧九节点演算机、指令级预算与自研编译器方案。

## 1. 三种颗粒度

策略交互的一步：提交一个真实决策的完整动作，游戏自动推进到下一真实决策或终局。下一决策可属于别人，也可仍属于自己；不要求一张牌已完全结算。自回归参数 token、赋值、循环迭代与函数调用不是环境步骤。

记录颗粒度：实际决策观察、动作、行为策略版本和预算、领域事件、结果、必要随机输入及程序/协议版本。玩家可见记录与授权全状态审计分开；不能把审计信息送入策略。最终状态差不替代领域事件，内核指令追踪是可选诊断。

快照颗粒度：首版只承诺支持的决策等待边界。该处必须保存规则继续执行需要的完整状态，包括局部值、待决请求、剩余流程、游戏随机状态与任务；可以由现成 VM 保存，不要求由自研 IR 表达。快照版本绑定，跨规则版本迁移不是默认能力。

## 2. 执行接口

```typescript
create(setup: Setup): GameInstance;
advance(instance: GameInstance, response?: DecisionResponse): AdvanceResult;
snapshot(instance: GameInstance): Snapshot; // 仅支持的决策等待边界
restore(snapshot: Snapshot): GameInstance;
fork(snapshot: Snapshot): GameInstance;

type AdvanceResult =
  | { kind: "decision"; request: DecisionRequest }
  | { kind: "terminal"; result: GameOutcome }
  | { kind: "fault"; issue: ExecutionIssue };
```

接口是职责定义，宿主通信可异步。无 response 仅用于启动/继续已获准推进；重复推进一个等待响应的实例不得隐式选择动作。GameOutcome 由游戏声明，不从引擎退出自动推断。

超时中止与可恢复预算让出分开：首版需要资源中止/故障报告，但不要求任意指令处抢占后续跑。资源中断归为实验截断/执行问题，不能判游戏输赢；被中止的半执行实例不得继续当成有效决策快照。后端若额外支持 yielded，在适配层单列能力，不能成为所有后端的硬门槛。明确的游戏限时决策仍是正常会话协议，不同于计算超时。

分叉必须隔离，不硬性要求 O(1) 或 COW；具体成本决定可用搜索预算。恢复不依赖重放完整游戏前缀。宿主 capability 的状态和记录游标若影响推进，需随会话一起保存或确定性重绑定，不藏于不可恢复回调。

## 3. 实例与调度

ExperimentInstance 管理实验配置和任务，GameInstance 是一局独立规则现场，PolicyBinding 是某参与者的策略版本与记忆。不要把它们混成同一个 instance。

```text
ExperimentInstance
  配置：规则 × 构筑 × 策略组合 × 座次 × 种子 × 预算
  ├─ GameInstance A → 脚本甲 vs 模型乙
  ├─ GameInstance B → 模型乙 vs 脚本甲
  └─ GameInstance C → 脚本丙 vs 搜索器丁

各局决策 → PolicyRouter → 脚本 worker / 批量推理服务 / 搜索器
各局轨迹 → 学习器 → 新模型版本 → 策略库
各局事实 → 实验估计 → 关系与覆盖图
```

不必遍历整个笛卡尔积，实验调度器按预算选择任务。规则产物、脚本代码和冻结权重可共享；可变游戏 context、玩家记忆、随机流、请求身份与分支记录必须隔离。同模型的跨局决策可合批，同一局严格按规则顺序推进。

## 4. 训练与推理

训练采样、评测与正式游戏使用同一策略决策协议。评测固定策略版本；采样记录实际行为版本，学习器消费符合算法要求的轨迹，产出新版本后显式切换。不能让评测局静默使用更新中权重，也不能把脚本动作伪装为 PPO 原策略样本。策略记忆与可重建的 GPU 缓存分离。

受限模拟仍从合法信息建立假设 GameInstance，复用规则和后端；只有获授权的分析实验可分叉真实全状态。动画留在前端，真实/虚拟时间是明确输入。
