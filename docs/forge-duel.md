# Forge Duel v1

这是有限卡池研究游戏，规则版本固定为 forge-duel-v1。卡池、费用和效果采用 implementation-spec.md 第8节：20生命、12张构筑、同名最多2张、起手各3张、每方最多30个自己的回合。每方第30个自己的回合结束而没有胜者时为正常平局。英雄受到伤害后立即检查终局；同次战斗的双方单位伤害、死亡移出和见证者触发按同批处理。

攻击受守卫限制，火花/爆裂的法术目标不受守卫限制。新单位本回合不能攻击，老单位每回合只能攻击一次。补给逐张处理抽牌、烧牌、递增疲劳与终局；终局后不再抽下一张。烧牌公开。修复与见证者回血上限20。见证者须在死亡批次处理后仍存活，只为同批其他友方单位死亡触发。

动作规范顺序为手牌顺序的所有出牌及其目标、场上顺序的所有合法攻击、结束回合。英雄目标在单位目标前，单位按入场顺序排列。实体、逻辑决策、动作和领域事实使用游戏自己的稳定键；通用 callId 不充当机会分母。

玩家观察只有自己手牌、双方公开生命/法力/单位/弃牌、牌库数量和合法可见历史。抽牌身份只对自己公开；烧牌、出牌、战斗与生命变化公开；携带和可用事实只供独立分析消费。审计事件不得送入策略。

基础构筑为 scout/guard/beast/witness/spark/supply 各两张。替换实验的槽位和配对种子由冻结实验配置决定。游戏不修改外部世界；假设构筑由 setup 显式提供，fork 原样复制。
