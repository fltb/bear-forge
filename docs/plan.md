### 当前实现与验证

- **共享代码、独立状态**：provider 保持 LoadedProgram，实例持有独立 Context；加载缓存仅弱引用 Program。fork/restore 不初始化作者代码，也不保存静态代码。context 正式测试检查共享身份、初始化次数和快照根；新增 Program 生命周期 GC 测试通过，确认所有句柄释放后代码可回收并重新加载。
- **快速分支**：默认路径使用对象堆、分页内存、内部槽、强/弱集合、任务队列的共享根；fork 不调用 prepareCopy 或序列化。32/4096 个保留对象的结构测试禁止 fork 和首次推进枚举堆；持久索引没有父分支链，安全整数索引深度最多 11，20,000 层分支测试通过。最新 32/4096/32768 档局部测量 fork 中位约 0.0140/0.0092/0.0145 ms，首次推进约 0.0729/0.0341/0.0350 ms；这些不是整局吞吐证据。
- **局部写入与隔离**：对象属性按索引路径复制，缓冲区按 4096 字节页复制；64 MB 缓冲区局部写入的结构测试验证未复制整块数据。闭包 cell、帧、模块数据、Future、迭代器、集合和字节内部槽均选择当前 Context；正式测试覆盖父子双向修改、多层分支、循环、别名、保存和跨进程恢复。
- **回复事务**：自定义 schema 在 COW 分支中执行；拒绝/取消不提交，接受后移交根并解除旧句柄所有权。关闭、恢复替换、取消验证立即清空旧根。预算和宿主访问故障仍按既定语义锁定，相关正式测试通过。
- **执行成本修复**：共享 Program；同步临时帧/局部槽不登记 COW，逃逸捕获仍独立持久化；当前分支独占条目可原地更新；原生准备缓存仅记录不可变品牌判断；已登记编译函数保留参数/返回值准入及预算语义，跳过重复原生分派。字面量属性初始化使用内部操作，避免辅助描述符和通用调用，并修复作者局部 Object 绑定遮蔽生成代码的问题。
- **可达性回收**：状态表使用身份与版本共同维持的 ephemeron 数据；关闭分支释放根，GC 清理死身份索引。已修复 await adoption 监听器、原生壳属性、Object.create、普通构造、原生子类、弱集合适配器和 __proto__ 字面量的旧引用滞留。39 项生命周期/原型/实例回收测试覆盖原始与恢复实例；长期活 Context 的临时对象、循环、保留分支及关闭根测试通过。没有通过扫描整个堆实现 fork 或首次推进。
- **当前检查**：最终一致版本的整仓 check 1,253 项全部通过，0 失败、0 跳过，所有模块类型检查通过，其中 runtime 205、compiler 85、controlled 697 项。六个固定 Test262 门槛全部通过：解析 205、编译 425、链接负例 25、同步 374、异步 38、运行期负例 7，范围内无未执行项。生产代码停止修改后的最终 build 已通过；公共 contracts/protocol 无差异，最终差异格式检查通过。未提交或推送，保留工作区既有改动。
