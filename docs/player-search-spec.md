## 当前决策目标与真实世界线

从真实当前 Context 向前比较动作及其局部后继，选择更有利于保血和尽快结束战斗的场面，避开明显致死的决策，兼顾可顺手获得的永久收益与药水等跨战斗资源。允许明确的游戏常识剪枝与中间场面估值。场面估值、经验剪枝、已验证的死亡结果、真实战斗终局与精确最优性证明必须分别报告；不能把高估分当作安全保证，也不能把未展开死亡风险写成零。

公开集火偏好加入剩余敌人负担项：`0.2 × Σ sqrt(max(0,HP)/max(1,maxHP)) / max(1,初始敌人数)`。平方根的凹性使同样的非致死伤害在残血目标上减少更多负担，避免只用剩余总血量时集火与分散完全同分；原线性总血量、存活敌人数、已发布攻击威胁及其他评分继续参与。它是可被其他收益/风险覆盖的启发式，不是伤害预测、击杀证明或对完整动作空间的删减。

持续力量/敏捷的评分特征扣除公开且仍活跃的 LOSE_STRENGTH/LOSE_DEXTERITY 层数，避免尚未利用的临时药水加成被奖励为持续成长。状态不活跃时不扣减，即使公开计数中还有旧值。临时属性的实际收益由原后继中的伤害、格挡等体现；该折扣不执行回合末结算，也不预测结算结果。

调度优先级与动作收益分离：同一根回合的公开能量给予 `0.04 × min(6,max(0,energy))`、当前费用不超过能量的非 X 费手牌每张给予 `0.006` 搜索优先级，以便原执行器继续展开扣血换资源等准备动作后的出牌。系数和饱和仅影响服务顺序，不限制动作、回合、能量或概率支持；FIFO 仍保留。未花掉的资源不增加 combatValue，不据此将准备动作判为有利。

实际只提交当前的一个动作。接受执行后，宿主将执行后的真实 Context 交给下一轮决策；即使走入必死状态，也不撤销、不回到前一步重新选、不恢复旧检查点重做、不重放。执行前的候选分支比较不构成真实回退。执行后的旧根只能作记录，后继缓存只有在满足信息约束且与新的实际状态一致时才可向前复用。宿主不再交付过期请求。最新真实现场丢失时报告丢失，不能借恢复之名回滚。

决策层信任宿主交付的类型化请求、当前状态与合法动作，不重复核对请求身份或完整 Context，不重新解析已投影的观察、动作和事件 schema。冒险偏好、唯一动作及同根续搜直接处理已有输入，不额外 fork/inspect。真实执行与动作接收归原宿主负责；决策层没有回滚入口。

冷启动按宿主当前请求选择要装载的搜索会话；其余历史根完整保存在压缩数据中，不为启动重新建立其全部执行状态。若最新已接受动作引用上一步会话，则按向前复用算法读取其后继；不重新搜索旧根或执行其旧动作。搜索存档直接装载原有执行、共享关系、概率边、信息集、队列和循环消元游标，重建派生索引，不重新核验整图、概率总量或已保存等价关系。相关正确性由生产写入路径及正式性质测试保证，不能用恢复重验替代算法正确性。

完整未来概率支持、原权重及未展开质量继续保留。局部估值不是部分结果重新归一化后的“完整期望”；对相同公开观察必须使用同一决策，禁止分别利用隐藏世界选最优。经验剪枝应标明依据及适用条件，不把它冒充数学支配证明。原规则执行器继续负责实际效果，评分不得成为第二套结算。

旧“中间估分仅排序”“完整当前战斗证书是出牌前提”不再是生产策略要求。下文精确证明内核保留为可选证据计算，其严格门槛只约束宣称精确证明，不阻止局部策略行动。生产局部接线及其验证状态见计划，不以本文声明替代实际检查。

构筑的角色评分来自公开卡组与原卡牌元数据。所有原 type=attack 的卡牌至少有基础输出贡献，即使尚无具名权重或只登记了群攻/成长角色；Blood for Blood、Immolate、Fiend Fire、Whirlwind、Searing Blow 补入高输出偏好组。具体权重仍为启发式，不是伤害公式或第二套卡面执行。已有这些牌的卡组同样累计其输出，因此新增攻击牌会受到输出过剩的边际扣分。

升级选择使用同一公开卡组中该卡位升级前后的边际构筑价值之差，计算时两者都以去掉该卡位后的公开卡组为基准，抓牌的重复副本、基础牌与卡组厚度扣分相消。另按原卡牌元数据的费用下降每点加 2，保留 Bash 升级偏好加 1；这些是启发式系数，不是伤害、费用执行或收益保证。原选择项的 deckIndex 决定该卡位，评分不修改真实卡组。重复升级卡的额外效果尚没有专门估值，不能宣称已覆盖所有升级收益。

局部动作后续估值、已知死亡风险及循环惩罚完全相等时，比较各动作一步后继的公开场面估值期望，优先已兑现的场面改善，避免候选顺序导致先做无收益动作再收尾。已观察结果按原概率加权，未知尾部取其已保留原现场的公共前缀估值，尚未开始的部分取源公开场面先验，质量完整保留；不按隐藏世界选最大值。此项只用于同分选择，不覆盖收益更高的铺垫路线，不声称最优性证明，也不增加真实执行或存档校验。

## 局部场面计算与当前实现取舍

局部选择在 estimate、已确认死亡、循环、立即后继估值及 U 全部相等后，才使用公开 `localTiePreferences`。当前仅用于 `EXHAUST_ONE`：原元数据类型为状态牌或诅咒牌的候选偏好 1，其余为 0。原候选、质量、估值和前沿不变；更好的已观察消耗组合仍优先，相同信息使用同一偏好，不用于精确证明。这是消耗杂牌的经验偏好，不能保证适用于所有依赖状态牌/诅咒牌的构筑。

`SearchSession.stepLocal` 沿用同一个 `advanceExecution`、概率前沿及公开后验发布机制。它不等待终局证书、不运行旧目标的循环求解或支配排除；只调度当前根可达且未被明确经验剪枝暂缓的公开信息节点。未完成的随机律仍逐步展开，但其中的隐藏单个后继只提供场面估值，不能独立选择下一步。旧根不可达任务及经验剪枝暂缓的任务原样保存，不在本次局部搜索中推进。调度仍交替服务公开高分后继、根候选覆盖及 FIFO，无深度、世界数或概率截止。

局部优先批次中，用于高分续行的访问先服务尚未完整发布、且至少一个已交付公开后继评分高于当前根的根动作律，以免确定动作的深层后继挤占随机多段攻击或抽牌动作的直接分布。候选按已交付公开后继的最高评分排序；这个乐观值只决定计算顺序，不回传为动作价值，不改 L/U，不按隐藏世界分别决策。另半批次的根动作轮转和批次之间的 FIFO 保持不变，因此无限有利分支仍不能永久饿死其他原工作。缓存仅累计已完成的公开投影，冷恢复从保留结果重建，不重复执行。

每个 31 步优先批次另取 7 次访问，在未被经验剪枝暂缓的根动作后继工作组之间轮转，按稳定节点/动作顺序服务各组任务，未完成边保留组内位置；其余访问按上述规则分配。这样一个即时低分的铺垫动作仍能继续到下一步收尾，不必等待另一个高分动作的宽大后续空间全部处理。工作组仅按原图首条可达路径分配，共享节点仍保留全部入边，原概率和信息集不变。组游标独立于未完成根律游标，保存到私有搜索调度状态，避免两条轮转互相重置造成饥饿；旧存档缺失时从 0 开始。全局 FIFO 与原已执行步骤保持，旧根不可达工作不参与这些组。

`localEvidence` 只读取保留的位置投影、概率边及未交付原现场的公共前缀，不调用 next 或执行任何原操作。STS 前缀通过同一原 stsPorts.frame 查询读取，Program 仅继承原查询的静态绑定，不新增规则解释或校验。 排序优先级与动作效用分开：STS 私有位置投影的 utility=(combatValue+1)/2 不奖励未用能量或仅仅变为可打的手牌；这些临时资源仅在 combatPriority 中影响展开顺序。utility 由同一公开投影函数计算；决策层不重复检查一致性、范围或有限性。冷恢复从保存的现存 Context 重新派生位置投影与索引，不执行已完成的边，也不额外重验这些数据。喝能量药水后若没有观察到生命、威胁、攻击进展或已生效能力的改善，不会仅因能量数值上涨获得动作效用奖励。此分离不限制概率支持，也不保证有限局部前瞻一定看到后续组合。场面函数 `q(s)=(combatValue(s)+1)/2` 在 `[0,1]` 中；它是启发式数值，0 对应原实际死亡。一个尚未完整发布的动作，已知后继的原质量为 `p_i`，剩余质量为 `r=1-Σp_i`，其局部评分范围为 `L=Σp_i q(s_i)`、`U=L+r`。所有质量和有理加权运算保持精确，场面浮点估分按其原二进制数值转换；即使质量小于浮点可表示范围也不丢失。不能用 `L/Σp_i` 替代完整范围。另给出决策用的 `estimate=Σp_i estimate_i+Σr_j q(c_j)+(r-Σr_j)q(s)`：c_j 是尚未交付的原 pending/ready 现场，r_j 为其完整精确剩余质量；chance 的质量包含所有未消费游标区间及合并余项。q(c_j) 只读取已经执行的原公共变化，例如抽牌之前已获得的格挡；它不是预测抽到什么，也不创建可选动作。未开始的部分，以及原事件回调/指令 yield 等不保证完整场面可发布的私有阶段，继续使用源公开场面先验；STS 只在随机边界和原决策/终局投影处提供前缀估值。不对已交付前缀归一化，不把原前缀估计当作终局值；随着真实后继交付，按原质量替换该部分估计。该点估计始终位于 L/U 内，未知质量继续报告，不用于精确剪枝或完成证明。

完整发布的信息集按原概率线性合成子节点的评分范围。已展开的后续公开节点可继续比较动作；没有后续结果的公开叶子使用场面估值而不冒充战斗终局；循环回边使用带 cycle 标记的场面叶子，不凭空假定循环会结束。遍历使用显式栈，无固定深度。整个评价中相同 information 键固定为同一动作，后来的隐藏后验不能换动作；这是一份依遍历顺序构造的公开局部启发式策略，不是最优策略求解。

局部前瞻在尚无后续观察的公开节点使用场面估值。只要已有后继结果，选定续行的加权 estimate、L/U、frontier 与未知质量正常向前回传；即使还有未展开尾部，也不能用较早场面的较高 q 覆盖已观察到的非致死损失或死亡风险。未展开部分已经按保留原公共前缀或尚未开始部分的源场面 q 计先验，不需要再用父场面替换整个续行。否则多加一个消耗资源的中间动作可能遮蔽同样的后续损失，错误奖励拖延。此规则只评价保留的局部图，不要求搜索到战斗终局，不改变支持、游标和剩余质量；frontier 不代表安全或未来风险为零。

动作比较先排除确定达到最低终局值的局部方案（存在其他可能方案时），再最大化 `estimate−minimumTerminal`；死亡惩罚系数 1 是明确的启发式权重，不是用户指定的最优系数或风险保证。它避免已确认死亡与普通低分场面完全等价；未知尾部仍不代表安全。证据同时给出 estimate、unknownPrior=source-public-board、confirmedDeathPenalty=1。平分时依次偏好较少已确认死亡质量、较少循环质量及较高 U。同一完整 Context 的单位质量自环，在存在其他动作时暂不选择，仍保留全部边。其余经验评分不会删除原空间。`unresolved` 是未交付随机质量，`frontier` 是使用非终局场面估值的质量，`terminal` 是原真实终局质量，三者加和为 1；`minimumTerminal` 和 `cycle` 分别标记已确认最低终局与循环叶子。L/U 仅约束这套启发式在未展开随机结果上的数值范围，不是真实离场血量、存活率或最优回报界限。

明确的业务启发式：丢弃药水本身没有即时战斗收益，不能仅因丢弃分支已确定、其他动作未来尚未展开，就优先丢药。若丢弃动作的局部 L 不高于当前公开场面的 q，本轮不接受该动作；若已观察到丢弃后的补偿收益令 L 更高，则仍可选择该组合。此规则可能延迟尚未充分展开的换药组合，不是数学支配证明。证据输出 `heuristicExclusions` 及原因，全部原动作行、概率律、剩余质量和待办仍保留，后续可继续展开；同一公开信息的重复节点使用同一排除集合，不按隐藏世界分别裁剪。

零能量 Whirlwind 的业务启发式：只有原直接后继质量已完整观察，且其 immediateEstimate 与局部 estimate 均不高于当前场面 q 时，本轮不接受该动作，证据原因是 `zero-energy-whirlwind-without-observed-benefit`。这是避免空耗/反伤动作因结束回合尚未观察而胜出的经验选择，不是无效果证明。化学物 X、原触发或已观察组合产生实际场面收益时不排除；不另算伤害，不删除原动作或概率空间。被排除后仍需从当前真实根取得其他动作原后继，再作建议。

另一条明确的经验剪枝仅针对基础 `STRIKE_RED` / `DEFEND_RED`：同一目标、原公开实际费用和全部公开卡牌属性均相同，仅 `uniqueId` 不同的手牌，局部搜索只推进并选择第一张作为代表。原完整合法动作仍保留；被暂缓动作及其后继待办进入 dormant，原概率律和未展开质量不变，证据列出 `duplicate-public-basic-card`。每个新公开状态重新计算，打出一张后其余副本仍可成为下一动作。不同目标、升级、保留、费用或 specialData 不合并，不跨牌型合并。该规则忽略实体身份可能带来的后续差异，属于用户允许的业务启发式，不是完整 Context 等价证明；不能据此签发精确完成证书。精确调度仍能访问全部原动作。私有位置投影的 localExclusions 必须在同一公开信息下保持一致，不能全部排除或指向不存在的动作。

当前待实局评估的系数：每多一回合在原场面效用上扣 0.025；公开未覆盖攻击意图达到当前 HP 时再扣 0.6，作为危险信号而非伤害结算或必死证明。生命、敌人剩余生命/威胁、格挡覆盖、状态及可用牌仍读取原公开字段。永久 maxHP/金币净收益的附加效用限制在 ±0.04，力量/敏捷附加奖励最多计算 12 点，避免无限堆积的辅助收益鼓励拖延。活着的战斗出口也扣回合成本，回合数读取原公开 turn/history/turn-start 事件；不重演事件。上述数字是实现中的启发式取舍，并非用户指定或已验证的最优权重。 敌方格挡不再作为独立的永久威胁扣分：它可能随回合消失，也可能由有利的原阶段切换产生，不能把削去格挡等价于削去生命。后续攻击能否造成实际伤害仍完全由原结算决定，并通过后继生命与当前意图反映；该估值会忽略尚未展开的破盾成本，属于明确的启发式取舍，不是支配或安全证明。

沿用已有 `schedulingMilliseconds` 作为检查局部结果的调度时点；时间片后有已观察后继即可选择估计动作，没有任何后继则保留前沿继续调度。有限工作队列耗尽也检查局部结果。资源或取消信号优先，不能因估分已有结果忽略取消。输出 `estimated-action` 和 `searchComplete:false`，与旧证书 `proven-action` 分开统计；不新增自动固定策略回退，不重新随机化已发生的真实动作。

## 根、规则与信息

根直接接收完整真实当前 Context，保留已经发生的状态与用户授权的当前敌人意图。根不 mask、不重造；未来未知量由原随机/排序机制展开，不使用真实隐藏未来。所有后继严格 next(current)，与真实游戏共用原 Program、卡牌、敌人、机制及生产结算。禁止重新初始化、动作前缀重放及第二套规则模拟。

公开观察相同的世界必须采用同一个后续玩家动作。条件概率必须沿已有分支保留；不能在每步重置未知牌序，不能把不同隐藏世界各自的最优动作平均成可实现策略。原 Frozen Eye 公开信息与当前意图授权继续适用。

真实敌人选招只执行原随机调用、原 choose 和原状态提交，不在正常执行时生成有限候选意图分布，也不维护历史粒子后验。原选招前后可保留无副作用概率标记；搜索遇到未来选招时从该当前执行位置展开完整随机坐标，并让原 choose 更新关联组件。已经确定的当前意图直接复用，不能为取得候选分布重新执行它。

## 完整概率前沿

概率执行暂停在原随机操作之前。一个待展开节点保存其当前 Context、父概率质量、当前原操作空间和下一个坐标。有限均匀空间使用 bigint 坐标；带权空间使用原质量。大空间不因数量阈值切换采样。排序可使用完整符号语言；未展开部分始终保留其空间和剩余质量。

排序空间按条件概率逐张选择：选择第 k 张后，后继保存已选前缀和条件化后的剩余语言，下一张从这个当前状态展开。原排序语言的所有权重、移除成员的位置边缘化、条件化及规范化使用有理数；不能先用浮点计算导致小质量消失，再把浮点结果包装成“精确”质量。完整排序结束后保存已实现顺序；只选前缀时，未公开后缀仍由原条件分布约束。

当原调用明确要求完整排序、当前知识没有额外位置语言且不是unsupported时，各连续交换块B的完整排列可以直接编码为大小 `N=∏|B|!` 的均匀bigint坐标空间。混合进制分解坐标后对每块解码排列，与逐张条件选择的完整路径一一对应，每条路径概率均为 `1/N`。这只合并排序内核中没有原回调的中间选择，不省略任何原洗牌、移动、回调或结果。游标保留全部未访问坐标及精确剩余质量，不提前生成N个结果；前缀揭示及有额外语言约束的排序仍走原条件选择。该优化减少内部节点，不消除排列数量的阶乘增长，也不构成完整战斗可完成的证明。

被丢弃的随机返回值只有在完整续执行等价已有证明时才能积分合并。目前仅登记原 `random.int`：其概率执行的组件写入仅为原计数器加一，不读取坐标，无事件、发布或约束；坐标唯一影响 `start + Number(c)`，在原已验证的整数区间内是全定义的数值。登记是内部源码证明义务，不能从“没有接收返回值”推断任意原操作等价。链接器保证绑定 atom 的结果只供自身 return 使用，执行器另检查它不是顶层返回且调用者没有接收槽；接收后暂未使用的结果也不合并。原调用、组件提交和立即事件调度仍执行，不跳过随机调用或改变计数。

对满足上述条件的当前操作，任意两个剩余坐标的未来可观察律相同，因此保留子测度 `Σ_i a_i μ|R_i` 可积分为一个后继，质量为 `Σ_i a_i μ(R_i)`。代表坐标取当前尚未执行的坐标，原游标的旋转、已消耗前缀、重叠区间和既有交付质量均保留其意义；不会重新执行已消耗坐标，也不把剩余质量归一化成一。旧存档原空间与游标直接恢复，不在恢复时执行合并或改写 Context。此项只消除已证明不可观察的坐标差别，不合并已实现洗牌、可观察随机结果或依赖坐标的写入。

未来洗牌一旦由原随机内核展开为具体排列 π，该概率分支就必须保留 π，后续 conceal 只改变玩家知识，不能再抽一次独立排列 π′。无中间操作时，两次读取的联合律为 `P(π) · 1[π′=π]`，不是 `P(π)P(π′)`；即使洗牌内部没有回调，调用者也可能在返回后观察顺序。仅检查洗牌到 conceal 之间没有观察者，不足以证明所有洗牌坐标等价。当前实现保留所有原洗牌坐标并将概率分支标为已实现；真实执行的知识状态仍按原路径保留未知牌序，供后续真实当前根展开。未经完整续执行证明，不启用排列代表合并。

随机插牌的隐藏排序必须继承原操作的合法位置，不能默认使用全部 n+1 个间隙。原 create 在 n>0 时调用整数空间 0…n−1，空堆只插入位置0；同一个 slots 值同时提供原随机调用的上界和 obscure 的位置范围。对于原条件序列律 μ，插牌后的律为各合法位置插入映射对 μ 的等权推前；交换语言按这份位置范围组合，不添加堆顶之后的位置。只有全部间隙均合法且原成员属于一个交换组时，才可化简为扩大后的单一均匀交换组。概率分支已经执行的插入仍保留其实现结果，后续读取不再次抽取位置。

直接自动打出顶牌也属于原排序的观察操作，必须先沿同一revealDraw入口解析顶牌的完整条件分布，再执行原移动和出牌队列。不得直接把真实根中尚未揭示的末项当成搜索答案。恢复中若修改概率律，必须审计已执行部分与未执行部分的联合分布；总质量为1不足以证明版本混合正确，不得只更换规则身份便继续。

有限整数映射使用各结果的原始出现次数除以源集合大小；float24 映射使用原区间覆盖的格点数除以 2^24。原拒绝条件保留的结果按接受格点总数条件化。上述比值直接构造 bigint 有理数，不经浮点权重中转。概率映射支持大小不设置任意硬上限；旧有限采样与分区辅助已经删除，不能作为完整搜索的替代路径。

一次展开只执行一个尚未执行的坐标及其原确定续行。父概率节点保留尚未执行的坐标；已生成子 Context 交给前沿，绝不从旧动作带重建。随机点之间的已执行确定前缀不重复运行。概率前沿满足：已交付质量 + 已到达边界但未交付质量 + 待展开质量 = 根质量。资源不足不改变这个等式。

确定续行也使用可更新的指令时间片；时间片用完时停在下一条尚未执行的原 Card 指令之前，保存原帧、局部变量与别名，继续时不再次提供已消费的动作或随机坐标。该停止不是游戏终局，也不消耗或重置真实根的累计预算字段。

前沿在有限局部续行批次之间插入公平服务。初始局部批次为 31 步；每次公平服务完成后，前沿不足32项时安排31个局部步骤，达到32项后安排63步；上界不随前沿继续增宽。63步保留较长确定性续行的局部性，避免在首个结果交付前打开整个有限叶子层。旧存档中已经安排的倒计时原样走完，随后采用固定上界。此前按前沿宽度平方增加的批次虽保证最终公平，却延迟后续原随机坐标，使先行坐标长期深入其子树；现优先保证各坐标及时参与完整当前状态等价合并。此项只改变调度顺序，不限制概率空间。每个节点保留非负 bigint 虚拟服务钟和初始为一的步长；执行一步增加该步长，随机游标分出一个子节点时，保留的游标与子节点都继承增加后的服务钟及原步长，不随已经枚举的坐标数翻倍，避免第 j 个坐标承担 2^j 的调度步长。已有存档中的正步长及服务钟原样保留，不重置已完成的服务。该次序与游戏结果概率无关；不按结果概率大小要求先展开整个巨大随机域。公平步选择服务钟最小的节点，并把随后局部续行交给它；局部结果交付后优先继续最近暂停的工作。每步服务钟至少增加一，每步至多增加一个游标后继，因此任意有限服务钟以下只可能有有限的原前缀节点。每个已有节点的服务钟有限，而固定的有限倒计时保证无限执行中公平服务不会停止，因此已有节点最终获得推进，即使优先路径无限。该次序不限制空间、概率、深度或执行次数；服务钟、步长、局部倒计时、调度计数与优先节点随前沿保存恢复。循环的全部概率质量仍保留。原 JS 原子操作内部目前不能抢占，不能声称已支持任意 JS 栈的保存。

坐标、前沿和搜索树均为可序列化数据，静态函数属于共享 Program。概率边界是原操作尚未执行的明确控制状态；内部保存恢复直接搬运原控制和数据，不重新校验原帧或待执行操作，不把它伪装成公共 IO。公共 Core/Instance/GameContract 协议不变。完整概率空间尚无精确实现的操作显式保持未完成，禁止悄悄采样或借用真实答案。

概率坐标采用可恢复的循环平移枚举：对原大小 N 的支持，第 k 个访问坐标为 (offset + k) mod N，0 ≤ k < N。offset 由搜索自己的机会节点序号确定性混合得到，首个节点仍从零开始；不读真实 RNG 或隐藏未来，不决定实际游戏结果。此映射是全支持的双射，权重仍读取原坐标对应的精确质量，只有原零质量坐标可跳过；游标记录访问数、偏移和剩余质量，恢复直接装载这些字段并按同一顺序续行，不重新核对剩余权重。其目的是避免每个机会节点都优先走坐标零、在原重复拒绝路径中持续下潜；它只调整枚举顺序，不能作为采样或限制支持的入口。

搜索快照包含不可变数据块和空原型对象的引用元数据；序列化不能把这些属性悄悄改成普通可变对象。兄弟快照可以共享已冻结的只读块，可变容器必须独立；恢复按元数据重建原图属性及别名，不执行原操作。共享仅减少相同只读数据的物理副本，不合并概率世界，也不构成状态等价证明。普通外部事件回调遵守冻结的批次重试协议；下述私有持久回执只对已登记的本地处理器生效。

压缩前沿逐项恢复现存 Context、概率游标、权重和已计算后继引用，不重查阶段、坐标范围、引用完整性或全图概率守恒。恢复只重建后续计算所需的派生索引；失败仍释放已建立的 owner。

压缩恢复复制输入编码与外部锚点表，直接保留独立 owner 的收起表示；实际访问时按原存储层恢复数据、所有权和别名。没有搜索专用 Context 准入或 image 校验回调；压缩图通用接口中的可选校验参数、校验缓存及其专用编码索引也已删除。每份 Context 恢复前的可用堆空间调度仍保留；它暂停工作且不消耗坐标，不是状态校验。

生产策略遇到 ExactProbabilityUnavailable 时，以 exact-space-unavailable 保留未完成工作并通知宿主保存。该状态必须保留原待执行操作和全部剩余质量；冷恢复再次遇到同一缺口也不能重做之前的前缀。此出口不代表实现了缺失的分布，不得记作完整搜索或已证明动作。

尚未实现完整概率内核的原操作用 unavailable 及具体原因标识，不接受任何坐标，也没有样本提交接口。保留缺失机制的现场只是避免错误推进，不等于实现其分布。第一至第三幕地图现已编辑为同一原构造程序的逐随机调用续行：当前地图、路径/父节点游标、原选中目标、待洗牌房间及洗牌游标保存在原 Card 帧中；真实执行使用原 RNG，概率执行仅将单次抽取替换为完整均匀坐标。第二条路径拒绝第一个起点时，原规则继续请求随机数；重复拒绝的任意长尾部保留，不能用有限次重试冒充整个联合分布。第四幕不请求随机数。原普通 generateMap 与生产 maps.generate 共用这一份构造函数，正式检查状态见 plan.md。当前战斗仍按原战斗结束标记停止，不包含下一幕地图。

## 可选精确证明内核（已有实现，非出牌门槛）

本节记录既有精确证明计算及其数学条件。以下“仅用于排序”“不参与动作接受”“完整战斗接受条件”等限定仅适用于该精确证书；2026-10-25 起，生产局部决策不再等待它们成立。该内核不得把旧根作为已经执行动作后的决策起点。

搜索区分玩家 OR 节点、概率 AND 节点和公开观察分组。只有原当前战斗退出或原游戏终局才产生战斗终点；决策数、回合数和调度时间都不是终点。存活与离场生命是主要目标，永久收益和药水使用是其次；中间状态分数仅用于安排展开，不是终局效用。

当前战斗排序与局部效用读取原已确定意图，使用未被当前格挡覆盖的意图量除以当前剩余生命，作为负向压力特征；同量威胁在残血时更紧迫，消灭攻击者带来的威胁消失也计入。系数暂为 0.5，是启发式取舍。该特征不计算实际结算伤害、不预测下一回合生命，不参与精确收益界限或支配证明；实际生命只来自原结算。超过当前意图量的格挡不因此获得额外奖励。

信息集工作队列采用有限优先展开批次与 FIFO 公平服务交替。每个公平步之后，若当时队列不足 32 项则继续 FIFO，否则安排 31 个优先步，批次内只递减；间隔至多 32 步，不随大队列规模增长。普通优先步在全部可展开任务中选择公开信息集估分最高者，同分时先比较已交付的共同条件质量，再优先续行上一步动作或其刚发布的未完成子边，否则保留队列次序。估分不读取某个隐藏世界的差异，不删除低分任务，也不参与界限或终局证明。每次已服务任务移到队尾，新任务也只追加；因此优先服务不能把旧 FIFO 任务向后推。前方有 N 个任务的已有任务，至多在当前剩余倒计时加 32(N+1) 个成功工作队列调度步骤内得到服务；循环求解交替占用的步骤另计。旧的平方级批次虽然满足最终公平，却使整轮等待增长到立方级，已替换。倒计时与优先任务随原搜索状态保存，已有倒计时原样走完，缺失此纯调度字段时从一次公平服务开始。完整动作律、信息约束、界限与终局证明条件均不改变。

为避免单个根动作产生的宽队列占满优先服务，每个批次在倒计时为16且可运行队列至少32项时，将这一个优先步替换为根动作分组 FIFO；全队列 FIFO 的时机、次数和上述等待界限不变。按当前根全部合法动作的原顺序，沿已发布且未被严格支配的边作多源广度优先遍历；共同后继归到首次抵达的工作组，原图中的所有其他入边均保留。根自身未完成任务归到对应动作组。分组仅分配计算，不重新划分后验、删去概率或选择实际策略。每次服务在各非空组间轮转，组内取原队列最早任务；任何通道服务过的任务均同步移到其组尾。根候选数和每组宽度不受限制。

分组及任务引用索引是可丢弃的派生缓存，发布、可达性/支配变化或根迁移后按完整图重建；无法从当前根抵达的旧任务仍保留为原暂停工作。轮转游标随私有搜索schedule保存，失败的原推进不提交新游标，旧存档缺少游标时从0开始且不执行原操作。根动作数量或归组变化不影响全局 FIFO 的公平性。公开优先分数、概率质量、收益区间、严格支配及完整战斗接受条件不因这条计算调度通道改变。

生产战斗在原 `battles.close` 和 `notifyCombatFinished` 的即时反应全部结束后，通过原 `stsPorts.frame` 计算退出视图，再到内部 `sts-combat-finished` 概率边界。普通执行穿过这个无副作用标记；战斗概率展开将该当前 Context 交付为终点，不继续执行奖励、地图或下一次冒险请求。边界值来自已保存的原执行帧，恢复读取不重做视图之前的结算。存档同时绑定展开的停止边界，禁止恢复时换成不同搜索范围。

概率边按原权重回传；玩家节点在信息约束下选择动作。未展开质量必须进入上下界，不能作为零质量忽略。只有依据真实终局目标证明某动作不会改善结果、或证明状态等价，才允许剪枝/合并。没有可采纳性证明的排序分数不用于剪枝或宣称最优。原有限前瞻 lower=estimate=upper 的做法废止。

当前代码将终局目标具体表达为按字典序最大化的期望向量：存活指示、离场生命、永久最大生命、金币、保留药水比例。死亡分支的向量为零；金币加 32768 将原有符号 16 位数值平移为非负值，不改变存活率相等时的金币比较。药水比例在 [0,1] 内。生命与最大生命的有限动态上界尚无证明，使用正无穷，不能把类型/schema 范围当作原程序增长路径的证明。此向量只在真实终点计算，中间估分不进入回传。

部分动作分布尚未形成完整后验时，基础下界累计已交付终局的确定质量和收益，每个已发布信息集还可使用下述共同策略路径见证提高下界；上界可以使用下文的信息放宽界限，未展开质量始终保留原域上界。所有父世界的动作分布完整之后才建立共同信息集，防止后到隐藏结果被分配另一套动作。随机节点对向量逐分量求带权和，玩家节点按字典序比较。发布动作证明须同时满足：当前根可达且未被严格支配的前沿及循环求解已经完成，候选动作下界不小于所有其他动作上界，并满足下述循环退出见证条件。只证明第一步的分数界限不足以构成完整战斗策略：不断把退出推迟到下一步，也能维持相同下界甚至相等上下界，却永远无法实现终局。尚无等价证明的无限历史因此保持未完成。被严格支配的前沿仍原样保留，不要求展开；动作证明与整个空间穷尽分别报告。

共同策略路径见证只读取已保留执行图：对每个已发布信息集分别条件化，对每个真实终局，沿现存入边索引回到该信息集的某个完整状态等价类，检查相同公开信息键是否始终使用同一动作。冲突路径不提供下界。无冲突的有限路径定义一个公开策略的部分映射，可在其他信息处按合法公共动作扩展。设该起点类后验权重为 `w`、路径各原条件概率为 `p_i`、真实终局向量为 `R`，则该公开策略的期望收益逐分量至少为 `w·Π p_i·R`，因为其他结果收益非负。每执行节点只选一条原入边，使不同终局叶对应互斥概率事件；起点类不同则初始事件互斥，相同起点类的不同叶必须在某一原随机结果处分离。共用前缀的质量在各路径中乘入，不额外当作收益相加。按单路径向量从大到小，为每个起点信息集的每个动作建立一个共同公开策略映射，仅加入与该映射完全相容的终局叶并求和。冲突路径不计入该下界，尤其不能把相反隐藏世界的不同最优动作合成收益。此贪心排序只挑选可行见证，不宣称最优，不删去未选路径的搜索支持；得到的完整向量再与原下界比较。该值用于各已发布信息集的动作区间，不发布部分后验，不替代真实动作或完整战斗证书，未展开质量与上界全部保留。

见证索引为每个已交付执行保留一条原入边的派生引用，遇到重复执行或不能回到该起点类时停止该候选证明，不截断原搜索。此选择可能漏掉更强的见证，不构成完整策略枚举或最优值；全部原入边和其他概率分支继续保留。以完整状态代表反向索引其所属信息集，一次沿终局原入边回溯可发现多个起点；对每个信息集仅采用该终局叶首次匹配的起点类，复制当时的公开动作映射，既不计入抵达该信息集之前的概率和动作，也不重复计入同一终局叶。随后继续回溯只为其他起点提供证据，不修改已记录的局部策略。新增信息集时也重建条件见证，不要求出现新终局。恢复从现存边、完整等价类和终局值重建该索引，不执行路径上的动作、不重建Context。接受公开后继并迁移根后，使用新根后验权重重算，已经发生的到达概率不再乘入新根价值。

动作支配只使用已成立的收益区间：同一信息集内，若 `L(a) > U(b)`（字典序），则由 `V(a) ≥ L(a) > U(b) ≥ V(b)` 得出动作 b 不可能最优，暂停 b 及其已发布后继的展开。这里比较的是共同信息集动作价值，不能在各隐藏世界单独剪掉不同动作。严格不等避免相等动作互相消除；无穷上界按扩展非负数处理，只有更早分量已经严格分出大小时才允许忽略后续无穷分量。启发式不参与这条证明。

被支配的动作、全部已交付后继、未展开概率游标及其剩余质量仍保存在原搜索会话中；暂停不是删除支持或把未知结果写成零。调度队列分为可展开和由支配证明暂停两部分，存档保存两部分全部任务。`pendingEdges` 表示全部保留的未完任务，`runnableEdges` 表示目前仍需展开的任务；后者为零不表示前者为零，也不表示整棵概率树已经穷尽。恢复从原当前状态、终局收益和完整条件质量重新回传区间、计算支配证明及队列归属，不执行 next，不信任额外保存的剪枝标志。该处理可以停止已被证明劣势的循环子树，但不等于解决仍可能最优的循环。

部分分布的终局贡献增量累计：对执行状态 `s` 和动作 `a`，令 `T(s,a)` 为已交付且成功投影的终局后继，缓存 `m(s,a)=Σ p(t|s,a)` 与 `v(s,a)=Σ p(t|s,a)V(t)`，求和范围均为 `T(s,a)`。父信息集权重为 `b(s)` 时，下界 `L=Σ b(s)v(s,a)`；原保守上界为 `L+(1-Σ b(s)m(s,a))M`，其中 `M` 为已证明的分量上界，零质量乘无穷按零处理。每个已交付后继只累计一次；投影或有理运算失败不提交该项的缓存游标。缓存只加速求和，不删 Context、概率边或信息集；存档保存原后继与质量，恢复从这些数据重算缓存，不执行 next，也不信任额外保存的估分。

已交付非终局后继可以用原执行证据收紧上界：对完整当前执行状态 `x` 的每个合法动作 `a`，令 `B(x,a)=v(x,a)+(1-m(x,a))M`，未打开的动作取 `M`。定义 `H_j(x)=max_a B_j(x,a)`，逐分量取最大值；终局直接取原终局向量。`H` 只是一步信息放宽上界，既不递归截断原搜索，也不解释卡面：所有未终局、循环或未展开质量仍按 `M` 处理。任何满足共同信息约束的策略，在每个隐藏状态的每个分量都不超过 `H`，因为放宽信息只能扩大可选策略集合，且 `B` 保留了全部剩余质量的上界。因此对父动作可使用 `Σ_s b(s)[v(s,a)+Σ_{x∈N(s,a)} p(x|s,a)H(x)+(1-m(s,a)-n(s,a))M]`，其中 `N` 是已交付非终局后继，`n` 是其总质量。这个上界逐分量不大于原保守界；它不是可实现的策略收益，不能提高下界、发布后验或直接证明完成。严格支配仍在共同信息集动作层比较。

进一步在已保留执行图上计算多层信息放宽上界：终局取原收益，尚未交付质量取 `M`；按显式栈后序遍历已交付非终局后继，递归引用已经证明的上界 `U(x)`，并逐分量计算 `max_a [v(s,a)+Σ_x p(x|s,a)U(x)+(1-m(s,a)-n(s,a))M]`。遇到当前遍历栈上的循环回边时，该引用仍取 `M`，不能假定循环终止或把它记作零。每个完成的值仅依赖终局、域上界或先前已证明的值，因此按计算顺序归纳即可证明其为上界，无须假定联立方程已收敛。所有后继上界不超过 `M`，故所得值不弱于上面的一步界限。显式栈遍历当前有限保存图，不设路径深度数值上限；循环的未知部分及原搜索前沿仍完整保留，这不是将循环或某层中间状态替换为终局。

终局前缀及非终局权重增量累计，非终局权重仅在已证明完整状态等价的代表上合并，原全部 Context 和边继续保留。一次回传内缓存推导值，新终局证据或相关后继证据变化后清空重算。纯派生反向依赖从真实终局证据构造最小不动点：一个动作已有正质量终局分支，或已有正质量分支通向候选执行状态时，该动作具备证据；一个执行状态的所有合法动作均具备证据时，该状态才成为候选。沿已保留的反向引用传播，纯循环不能凭自身成为候选。若某个动作没有这种有限证明，有限上界展开仍须为它保留 `M`，整个节点不能改善父上界。候选不保证实际收紧。新候选没有任何父分布引用时不触发整图回传；晚到父边同样登记。交付证据只增不减，候选集合单调增长。待处理的纯依赖工作集跨异常保留。索引更新和纯算术完成后才提交前缀游标，异常只能重试派生计算，不能重复原转移。恢复只从原保存的后继重建这些派生索引，不新增存档字段，不重新执行历史。更深证据的利用不意味着已获得完整战斗的紧上界或完成证书。


价值回传只在依据变化后执行：已投影终局的累计质量/收益改变、完整后验发布、循环证书推进，或真实当前接管时使派生值失效。仅推进原指令或交付尚未发布的非终局后继，不改变上述区间公式，不需要扫描全部信息集。失效标记先于相关提交，跨异常保留；完整回传成功后才清除。读取证据、保存及下一次调度前都先刷新失效值；冷恢复仍从完整原始数据重算，不保存或信任失效标记。

根分组通道在当前根仍有未发布且未被严格支配的动作律时，只在这些根动作之间按原动作顺序轮转，直接推进对应根任务。已有完整分布的后继仍由普通优先与全局FIFO服务；当前根的这些开放律全部发布或被严格支配后，该通道恢复原根分组FIFO。通道频率、全局FIFO位置与等待界限均不变，根游标仍按原动作索引续行；无穷根分布也不能停掉其他工作。此调整不改概率、公开评分、下上界、完整分布发布或战斗接受条件，不新增私有存档字段。

公开优先级相同时，局部调度先比较动作已经交付的条件概率质量 `D(b,a)=Σ_w b(w) d(w,a)`，其中尚未开始的律取0，完整律取1，其余使用原展开器的精确已交付质量。较大的D优先，同D再用既有局部偏好破平分；定期FIFO服务不变。世界拆分为若干同律且总权重不变的表示不会改变D，不能按世界个数或平均完成比例代替后验权重。这只是优先收尾的启发式：概率质量不是剩余计算量，更不是收益或完成证明；任意小的未展开正质量仍保留并阻止完整后验发布。高公开优先级仍优先于该破平分规则，无穷尾部也不能取消其他任务的公平服务。该排序只读取已保留分布，不执行原步骤，不增加存档字段。

排序所需的已交付质量直接读取展开器现有 transferred 累计值的独立副本，不重新遍历未消费游标或待交付结果。该值仅在 take() 转交现存后继时增加；恢复直接载入。masses() 保留为概率汇总接口与测试使用，不在恢复中调用它核验质量。

最高公开优先级任务可建立派生索引，内容严格等于原可运行队列的最高分子序列，保持原相对次序。队列中某任务服务后移到末尾时，它若属于该子序列也移到子序列末尾；否则子序列不变。新后验发布、任务集合变化、支配/可达性调整或换根时使索引失效，下一次局部服务重建；冷恢复不信任或保存索引。这样局部选择只扫描最高分任务，但同分质量、局部偏好和队列次序的破平分与完整扫描相同，FIFO仍直接服务原队首。动作的已交付质量始终现读，不能缓存为旧值，因为其他信息集可能推进共享执行律。索引不持有独有概率状态，不移除较低分任务，也不参与收益证明。

概率前沿交付后继时，搜索树先记录现存 Context、父边及概率质量，再计算纯观察投影；投影失败仍可保存并继续，不重新执行已交付的边。信息分组由原算法计算并一次发布，不额外跑分组校验。原执行器完成后，概率结果导出失败不能把已提交的当前状态改写为 fault；原规则执行本身的错误仍须如实报告。

执行状态等价采用保守充分条件：同一共享 Program、相同公开决策及完整原当前图等价；STS 还要求保留的原公开事件数据一致。当前图按对象引用的一一对应比较，保留别名、循环引用、属性顺序、数组空洞、原型、原控制帧、调用计数、预算、隐藏机制状态和条件随机知识，不为提高命中率删掉字段或重命名计数。相同玩家视图或终局分数本身不构成等价证明。该条件可能漏掉可证明等价的状态，但不得把不同的未来行为认作等价。

STS只读决策投影可在完整当前图等价、原事件数据一致时复用。缓存保存独立的不可变parked见证，不能拿可能已被调用方推进的旧owner充当证明；摘要仅定位，仍调用完整sameCurrent核对。只保存成功读取的原决策，返回位置重新分离数据并计算启发式；不缓存或执行回复，不改变概率边或存档。所属原current关闭时释放见证，不能令投影缓存额外保留已关闭前沿。

该私有缓存以无损压缩的V8数据保存完整原决策，命中后解压得到独立数据，不再同时保留另一整份事件对象图。完整原事件的规范JSON键及战斗信息集键使用确定的DEFLATE/base64编码；解码是左逆，因此两个压缩键相等当且仅当原规范公开数据相等。这不是摘要、观察删减、历史截断或状态等价放宽。所有字段、事件次序、Unicode及既有实体关联规范化均保留，完整Context见证仍按sameCurrent检查。派生信息键不写入搜索快照，冷恢复从保存的真实当前状态重建；原分组相等关系、概率、动作和终局值不变。缓存命中不重新读取或执行规则，启发式仍针对当前initial输入重算。

STS 搜索当前节点与动作展开的事件历史用完整 V8/DEFLATE/base64 保存。分支和快照复制字符串，追加事件前解码；原事件仍由 contract 投影，不在搜索重复解析 schema。旧数组存档直接转换，不验证编码或事件形状。外部访问取得独立可修改数组，后续保存反映修改；历史数据不用于执行。

不可变数据还保留来源区别：由同一执行器在 Context 初始化或续行中创建、且晚于 Program 绑定的数据，可按完整别名图对应；外部创建或 Program 绑定前已经存在的对象仍按物理身份锚定。规则不得把运行期可变闭包或 Context 引用藏在共享 Program 中，这沿用原执行边界。快照保存相对的 Context 数据身份标记，并保留嵌套外部锚；不序列化进程内的分配时钟。恢复直接重建这些所有权关系，不初始化或推进原程序。复制的外部锚与原 Program 对象仍不等价；全为 Context 自有数据的冷恢复后继可以复用。原调用计数、RNG 和隐藏字段继续完整比较。

单个动作的概率展开也可共享仍未执行的条件后继。仅对同一展开内的 chance 节点建立候选索引；摘要只用于找候选，必须再逐项确认完整当前图、共享 Program/trace、原随机坐标律，以及附带公开历史数据的原型、属性顺序、别名和循环。不同隐藏状态、外部身份或元数据别名均不能因摘要相同而合并。不支持比较的数据类型只失去复用机会，不丢弃该节点。

设这些入口的权重为 p_i，尚未消费的坐标集合为 A_i，原随机坐标律为 P(x)。合并后的坐标质量严格为 `P(x) × Σ_i p_i 1_{A_i}(x)`；同一剩余集合的特例为 pK+qK=(p+q)K。旋转游标的剩余集合是一个循环区间，按端点划分成互不相交的带权区间；交集权重相加，差集保留原权重，均沿用原 P(x)，不重新归一化。均匀空间的划分只处理端点，不枚举巨大坐标域；加权空间仍保留原逐坐标有理权重。只有零质量区间可丢弃。已交付坐标不进入 A_i，历史结果完全不动。

所有分段共享一个已经存在的完整 Context；私有展开存档以主游标和可选 `remainder` 数组保存各段游标及入口权重，旧无数组存档继续直接恢复。合并只运算分布数据，不 fork 新 Context 或执行原操作。实际取出坐标时才从这个当前 Context 分支，保留其他所有带权区间；最后一个坐标可以直接接管当前 Context。待展开总质量是各段入口质量乘以原剩余质量之和。恢复核对每段游标、原空间、入口权重和总质量，完整保存恢复所有分段，不能遗漏差集。

候选索引不进入存档，恢复从保存状态重建。阶段、游标和调度更新先于索引操作提交，失败仍保存已经推进的现场。合并仍要求原空间、元数据和完整 Context 相等，这是决定能否合并的算法条件。概率空间、坐标、游标、排列与单调映射、质量算术均信任类型化内部输入，不逐次验证。

STS 持久化保留完整 Context 的压缩表示。每份数据图采用无损字节编码，外部不可变身份锚点保留在字节之外，让外围存档继续维护跨当前节点的引用一致性；Context 自有图的字段、别名、循环、空洞及原型元数据全部保存。搜索根及各执行节点逐个保存，动作展开逐条保存，避免同时物化整个搜索前沿。恢复按节点/动作展开解码，由执行层恢复原 Context，搜索层直接连接保存的图数据；兼容既有原始 Context 存档。编码和解码仅处理当前数据，不初始化或执行任何规则。

已收起 Context 的持久化直接复制完整压缩编码与外部身份表，导出容器独立。搜索专用的控制状态校验、校验器缓存及阶段校验回调已经删除；保存与恢复不调用原操作，不重演任何历史。原宿主保存与真实执行的边界规则独立保留。


压缩块复制使用弱键映射复用已冻结副本，但源对象身份本身不证明内容。每次读取源块当前完整字符串并与副本逐字相等，才允许复用；源内容改变或数组项替换后重新走原驻留比较。内部冻结块也经同一完整字符串比较。外层数组、旧字节数组和锚点容器继续独立；仅共享不可变字符串块，不增加快照字段，不信任外部摘要或冻结标记，搜索恢复不进行 Context 准入。

压缩存储层也删除编码结构、字节类型、分块类型与 Base64 往返校验；压缩图不重验属性、镜像结构或锚点表，复制和解码直接处理自有编码，不留校验开关或兼容路径。解压本身的异常照常传播。

随机与隐藏排序的内部输入直接进入概率计算。删除整数范围、float24 映射区间/单调性/覆盖、声明长度和一致性、排列坐标/成员、分组、公开键、语言完整性及概率和重验；分组随机空间不再额外排序一次作校验。原概率执行入口不重验指令时间片、坐标存在性或边界形状。保留条件化、精确权重、支持空间、合并相等条件及不可用空间报告；这些是算法工作，不是输入校验。

搜索恢复直接装载可信的自有存档，首次恢复也不以解码证明控制合法性。每个恢复结果仍为独立 owner，写入和关闭互不影响；压缩编码的共享与状态等价沿原存储语义处理。

完整压缩字节、逐项外部身份和所有权边界相等时，独立当前节点可共享私有不可变镜像。各执行 owner 保持独立，导出容器分别复制；相等比较服务于复用，不是存档有效性校验。

只读激活后保留原不可变压缩镜像；未修改时再次收起直接复用。受管字段写入、删除、数组长度修改和新对象编码使原镜像失效，新的保存反映当前数据。所有权边界不同重新编码，搜索不再对新旧镜像运行控制校验。

已完成的随机坐标后继也保留复用。对于同一共享 Program/trace 与完整 Context C，原概率执行器推进坐标 x 得到已保存的后继 N(C,x)；再次遇到完全相同的 C、x 时，直接分支这份后继数据，不再执行其原操作。缓存不存概率权重，调用方仍用自己的入口质量乘以原坐标概率，并保留自己的公开历史元数据；因此不同入口仍按各自条件概率进入同一原后继。摘要只找候选，完整当前图比较仍是必要条件。缓存当前状态池对完全相同的源/后继共用一份只读见证，以整数索引保存边；原始无缓存存档继续直接恢复。只含一个正质量结果的步骤仍直接原地续行，避免为没有分叉的标记额外复制。

已执行的原步骤先提交为 inspect，再保存可复用后继；缓存分配失败保存已推进现场，不得重做该坐标。缓存恢复直接接回现存源、后继和坐标引用，不重新检查它们。压缩图的完整相等仍用于未来计算复用；分支共享不可变表示，执行时各自解码。

运行资源仅调度可续行工作。每次 scheduling yield 目前都会完整保存搜索前沿，因此调度片过短会让导出占据大量时间。开发实局可在记录完整旧/新登记及检查点的前提下调整这一操作参数；它不得改变概率支持、深度、原状态、种子或已有搜索成本。较早失败实局曾将调度片由2秒调到20秒，并提高内存及批次资源；其失败现场保持不变。当前独立实局1415925629的调度片保持2秒，RSS暂停阈值已由1 GiB逐步提高到4 GiB，任务/批次时间先由2分钟延长到10分钟，375803步整份恢复测得约354秒后再延长到20分钟，以减少完整前沿反复恢复成本。各次修改均保留完整登记修订；资源退出仍保存完整当前工作，不从旧检查点重做未持久化动作。

未活动的私有搜索 Context 可收起执行存储表示：保留完整数据图、不可变身份锚、null 原型及相对 Context 所有权标记，释放代理与 COW 索引。机器、共享 Program、trace 和尚未领取的原操作声明仍留在原机器上；收起不执行规则，也不改变控制位置、输入或概率游标。重新访问时先完整导入数据，再交换存储所有权，失败保留原镜像。收起前的临时代理视图失效，不能误指向重新编号的存储行。别名、循环、数组空洞、原型及外部对象身份必须保留。直接保存已收起状态只复制数据与元数据，不为导出重建执行索引；所得可变数据与原镜像分离。

收起镜像以 V8 数据序列化和无损 DEFLATE 压缩保存。较大镜像在完整序列化字节上按内容划分数据块，分别压缩并共享完全相同的块；块是只含冻结字符串的私有对象，摘要仅定位候选，完整字符串比较才允许共享。分块大小只决定存储表示，不限制 Context 大小、概率空间或搜索深度。旧单块镜像可直接解压、按相同原始字节分块，无需导出游戏对象或执行任何规则。保存容器保留共享块身份，解码按原顺序连接，逐字节还原原序列化数据；输入块、数组及身份表不能修改仍持有的镜像。块池仅弱引用数据，不持有 Context 或 Program。候选摘要基于完整未压缩字节，不能代替完整数据和锚点身份比较。Context 自有块连同全部别名一起编码；外部及 Program 绑定前的不可变对象留作原物理身份锚，通过独立的引用表连接，不能把它们复制成新的身份。占位表不占用任何用户字段名；稀疏数组、循环、特殊数值和 null 原型均保留。压缩字节数不含保留的外部锚，不能把该指标当作总内存占用。解压仅恢复数据与身份角色，不调用原规则或初始化。

若两个当前状态在上述条件下等价，则任意同一合法动作的下一步完整概率律相同，可以共用一份正在展开或已经完成的动作分布。每个历史仍保留原世界权重，并在完整分布后按公开观察形成后验；复用的是原执行后继，不是分别优化隐藏世界所得的值。分布新增终局贡献时，所有使用该当前状态的信息集及其祖先均更新区间。原始重复 Context 暂保留为等价见证；存档只保存代表状态的一份动作展开，其他状态引用较早代表，不复制已消费游标。恢复直接按已保存的代表关系连接共享展开；不能通过执行历史检验等价。比较被资源暂停打断时，已交付后继和质量仍在父边中，保存其尚未识别状态，恢复只重做纯比较。证据单列 `equivalentExecutions`，不把它当作已求解循环数。

完整信息集发布前，已交付的当前状态也可提前执行其合法动作，所获后继保留在该执行状态的同一动作分布缓存中。每32个搜索调度步骤至多安排一次这种续行，其余仍按原信息集/循环公平调度；这是工作次序，不限制动作、深度或概率支持。优先级只来自当前公开位置，所有原操作仍从现存Current推进。信息集发布必须继续等待父动作的完整概率律；提前计算的隐藏世界不获得独立策略值，不能分别选最优再求期望。完整后验形成后复用已消耗边和剩余游标，禁止重复执行。存档仍保存所有执行状态和动作分布；已发布代表集合由完整信息集重建，不新增历史重放或第二种根。

提前续行保存当前执行/动作的调度指针；原动作交付子节点后，优先沿该子节点继续，即使其公开估分较低。指针不发布策略或丢弃其他动作；主搜索公平服务保持。旧存档没有该可选字段时从null开始，恢复直接装载已存执行引用和动作。

共同后验按完整状态等价类聚合有理数权重。只有公开决策一致、每个等价类的条件质量也完全相同，才能共享同一个信息集节点；公开观察相同但后验不同的节点必须保留。节点的 `parent` 仅记录首次发现路径，真实依赖以全部已发布入边为准。支配调度从根沿所有未被支配的边计算可达性，不能因首次发现路径被支配就暂停仍由另一条有效路径使用的节点。恢复保留各条边的完整条件分布及首次发现关系，直接装载多条入边和自返回；概率与后验性质在正式测试中核对。

跨实际决策复用只读取宿主接受动作后提交的策略记忆引用。沿该动作已完成的分布，先按新公开信息找到唯一后验；只有该后验在比较实际隐藏状态之前已被证明只有一个完整状态等价类，才比较全部见证与真实当前 Context。通过后由完整实际 Context 接管该节点及其已消费分布，重置世界调度游标，原根、其他前沿与数学工作仍保留。混合后验不得借实际隐藏状态挑选其中一个世界；不等价或动作分布尚未完成时保留旧工作，从新的完整实际当前状态搜索。该充分条件保留真实 RNG 和控制字段，因此随机执行后可能无法复用，不能将其称为所有决策的复用保证。冷恢复允许搜索焦点位于非零节点；未从新根可达的循环数学工作不继续调度，但仍保存。

策略记忆只存搜索条目与已接受动作的引用，不存 Context 或可执行历史。成功复用后移动现有条目的公开请求身份；同一新请求的取消重试优先使用该条目，不重复接管旧根。每次实际换根保存本次决策开始时的累计步数，证据同时报告累计 steps 与本次新增 decisionSteps；实局汇总累加后者，避免把复用的既有展开反复计费。强制单动作不计为已证明搜索。

当前已接入单信息集自循环的精确消元。设完整动作 a 返回同一后验的质量为 `q_a`，其余后继 j 的质量为 `p_aj`。当 `q_a < 1` 时，重复该动作直到离开这一节点的条件分布为 `p_aj/(1-q_a)`；这是完整几何级数的精确和，原图仍保存自返回边与原始质量，不枚举有限次后丢掉尾部。相同完整后验确保下一次使用的原条件分布不变。Bellman 自引用 `V=max_a(q_a V+Σ_j p_aj V_j)` 的最优终局收益可按这些规范化外部后继比较；向量逐分量求期望、按字典序比较，边的原一步收益仍用原始质量回传。正概率不设阈值，即使退出概率为 `2^-100` 也不改成闭环。

`q_a=1` 的纯等待不能改善最优终局收益；其一步价值可能因为之后可以选退出而与退出动作相等，但实际选择必须优先能离开的已证明动作，不能每次重新选择纯等待来冒充收益可达。若所有合法动作都完整证明为纯自返回，则没有任何终局可达，已实现终局收益为零；这不是死亡、胜利或战斗结束。证据标记 `closedNonterminalLoop`，生产策略以 `closed-nonterminal-cycle` 保存未完成现场。该结论来自完整闭环证明，不来自深度截止。

多节点共同后验循环按强连通分量组织。只有分量内每个节点的所有动作分布均已完整发布，才建立该有限分量的策略求解工作；未知动作继续保留，不把它的样本或局部结果当作完整转移。策略为每个共同后验选择一个动作，不能给同一后验的隐藏世界分别选动作。对有限、仅在退出时取得非负终局收益的决策图，确定平稳策略足以取得最优期望终局向量；按原动作集合完整枚举这些策略，枚举总数为各节点合法动作数之积，没有采样或数量截止。最坏成本可能指数增长，必须报告待处理策略数，不能把尚未完成的枚举称为最优证明。

每个策略的首次离开分量的概率律通过精确状态消元计算。消去 k 时，`P_ij ← P_ij + P_ik P_kj/(1-P_kk)`，并移除到 k 的边；自返回质量为 1 的闭合类转为明确的“永不退出”结果，其质量仍保留。每个起点有独立的探测行，因此一次消元得到所有起点的首次退出律，不重复执行任何原游戏边。只在真实外部后继上套用当前收益区间；永不退出的路径不产生终局收益，不伪造死亡或胜利。尚未枚举完时，已完成策略只给出可实现下界，上界保留未知；枚举全部完成后，分别对各策略的上下界取字典序最大值。

消元同时保留 `E[T·1_退出到j]`，T 是到首次离开分量的决策步数。它不改变存活、生命、永久收益和药水目标，只在终局收益相同的策略中先选择较高的退出概率，再选择较小的退出步数期望，避免价值相等的纯循环策略取代可实现退出策略。循环根只有在该分量所有节点收益区间均已精确、策略枚举完成且所选策略退出概率为正时，才发布对应动作；证据包含策略序号、退出质量和步数矩。所有策略都无法退出时仍保存为 `closed-nonterminal-cycle`，不当战斗结束。

策略枚举、当前主元、正在消去的行、行中的精确质量和步数矩均进入私有搜索存档；一次调度至多处理一行消元，代数工作与原后继展开交替调度。完整图身份不同的缓存分开保留，分量扩大时不丢原执行前沿或旧数学工作。恢复核对图、动作序号、质量及游标，不重新初始化游戏或执行原动作。完成的首次退出律还须满足原转移方程 `h_it=P_it+Σ_j P_ij h_jt` 和 `m_it=P_it+Σ_j P_ij(h_jt+m_jt)`；无法到达任何外部出口的闭合状态必须满足 h=m=0，排除循环方程的虚假调和解。纯代数工作同样在每个调度步前检查已有的内存压力阈值，压力暂停保存消元现场，不改用近似策略。

循环不能通过固定深度消失。完整当前等价、后验复用、自循环与有限强连通分量求解均已编辑，尚未正式验证。不断出现不等价状态或不同后验时，空间仍可能无限，必须保留前沿，不承诺该情况有限时间收敛。更一般的等价论证、状态支配、跨实际决策复用以及当前全图回传和策略枚举的实际成本仍需审计，不能用有限夹具替代生产验证。

## 分层与生产接线

战斗只针对当前战斗作局部前瞻，无须完整搜索到离场；事件、奖励、商店、路线使用公开构筑需求及用户允许的独立随机偏好。原手写偏好属于待审查实现，不是用户指定参数。唯一动作可以直接执行，但不能据此跳过其合法性或真实推进。

抓牌的角色贡献按边际构筑价值计算。对输出、防御、运转、成长、消耗与群伤的原公开加权轮廓 x、现有阶段目标 T，以及候选增加量 r，使用 φ(x)=1.35x−x²/(2T)，角色增益为 φ(x+r)−φ(x)=r[1.35−(x+r/2)/T]。升级牌的 r 沿用轮廓中的 1.15 倍权重。该凹函数使相同角色越充足，后续牌的边际价值越低，过剩时可以为负；不再保留达到目标后仍为正的角色贡献下限。原开局输出偏好、卡牌品质、协同、重复牌及牌组体积项继续另外计入，角色贡献不是伤害公式或结算模拟。已有力量、消耗等协同可使本来过剩的牌重新值得抓取；缺运转或防御不会因攻击充足而被一起拒绝。跳过仍为合法候选，独立随机偏好仍可选择较低分候选，不宣称确定拒绝所有低价值牌。这些数值与角色表都是显式启发式，须通过实局评估，不能据此证明最优构筑。

停止调度、局部动作选择与精确证明完成分开。局部策略允许在未获得整场证明时选择动作，必须明确估计依据和未知质量，不冒充完整搜索或精确最优。纯调度/资源暂停仍保存当前未完成工作。保存真实游戏当前状态、搜索持有的当前分支、概率坐标、信息集、树边和队列；恢复后从这些现存状态继续。执行过的边不能因为清理、跨决策或重启再次执行。策略未完成工作通过宿主私有组合能力保存，不塞入只在动作接受后提交的 JSON 策略记忆，也不增加公共 Core/Instance/GameContract 字段。不得擅自设定开发种子总额度；游戏种子只用于实际对局，不代替未知未来空间。

生产注册使用 `gameSeeds` 表示实际游戏、`policySeeds` 表示局外偏好的独立随机游标；不再提供算法切换、粒子数、模拟次数、决策深度或回合上限。`schedulingMilliseconds` 是可续行展开及局部动作检查的调度时间片；根获取、恢复与证据计算仍计成本，但不能使每次冷恢复都在展开前耗尽时间片。注册只填充默认值并读取现有字段；不保留旧字段校验器，也不把旧字段别名为新算法。单次宿主调用的时间、步骤和内存设置不代表开发总额度。

宿主 RSS 含等待 V8 回收的临时执行结构。STS 命令开启宿主回收接口；触及原登记 RSS 阈值时先尝试一次同步 major last-resort 回收，再读取 RSS 决定是否暂停。没有回收接口、回收失败或回收后仍超限时，继续走原保存暂停路径，不提高阈值、不丢前沿。回收成本计入实际宿主耗时。策略已接管恢复工作后，宿主释放对原输入前沿的重复引用；磁盘检查点保持不变。

外层 attempt 调度只保留检查点的步数、累计耗时和工作标记，不把用于检查这些标量的完整反序列化对象保留到内层恢复结束。正式生命周期回归在同一次尝试的冷恢复中检查重复输入前沿可被回收，同时验证原初始化、动作前缀与已展开工作没有重执行。

策略的恢复入口先以完整无损压缩数据持有待接管搜索，等待真实当前分支提供同一原 Program，再解压并恢复 SearchSession。此前在等待期间复制并保留整份展开前沿，会在首次策略调用前就触及宿主阈值。压缩不改变对外保存的搜索结构；未打开的工作再次保存仍返回独立的完整快照，修改恢复输入或导出值不影响策略持有的前沿。恢复失败时保留原压缩数据以便报告和保存，不执行已完成的边。

STS 搜索实验的真实执行也使用同一 CardMachine 的可续指令时间片，但关闭概率替换，继续执行原随机操作及伪随机数状态。加载器保留正在执行的原 Context，在时间片之间让出事件循环，只有原 IO/正常终局才交给公共 Instance。已接受回复只传给第一片，之后以无回复续行。该入口不读取旧 computeStepBudget 字段，既不扩大累计上限，也不把上限耗尽变成死亡或成功。其他显式请求累计预算的非搜索消费者保留原行为；加载器拒绝同时指定累计预算与时间片。

真实实例的稳定 IO 存档标识执行方式，恢复不能悄悄切回累计故障预算；时间片大小可以改变，不改变游戏语义。执行中取消/资源不足的私有持久化已按下文接入，尚未正式验证；初始化、未提交原子操作及硬退出尾部仍有边界，不能据可让出调度宣称已解决所有恢复问题。

原执行器内核已增加私有 `ScheduledAdvance` 工作状态，加载器的可续时间片驱动复用它。状态区分待推进、已提交但待导出、已发布原 IO/终局；提交回调在原帧提交之后、结果导出之前标记回复已经消费。导出失败保存的是已提交现场，续行先重试纯导出，不再次执行原指令。私有快照只保存当前原 Context、不可变数据块标记和上述阶段，恢复不初始化、不执行概率替换；原执行可以在 RNG 指令之前让出，校验不得套用“概率执行会先停在 chance”的边界顺序。它不进入公共 Instance 快照协议；内核快照须与下述 Controller、GameHost 及策略事务组合，尚不能据单层保存能力宣称实验宿主中途恢复完成。

Controller 已把接受过程表示为 advance/publish/ready 三个显式阶段，私有快照包含已消费 callId、停止状态、已写入返回记录及是否记录。恢复时不重调旧回调，不再次向 advance 交付回复；advance 阶段只调用提供者对现存指令 Context 的 resume，publish 阶段只发布当前结果。发布失败保留阶段；成功返回接受结果后才清掉事务。尚有接受事务时公共 inspect/run/transfer/bind/close 返回 busy，不能把旧 call 冒充可重新选择的当前请求。生产加载器和实验已接入私有暂停、保存、恢复及所有权交接，当前代码尚未正式验证。

GameHost 的正常 run 使用显式事务保存此前接受的动作、当前正在消费的 callId 及其动作。私有序列化与 Controller 消费的 callId 核对，并保存原派生 view、请求、事件及事件回复；原 contract 的 port 函数和绑定回调不入快照。它区分“正在消费玩家动作”和“动作已接受、正在继续后续事件”。冷恢复核对原 host stop、请求/动作身份及阶段，直接载入已发布适配结果，不再调用 receive/respond/observe/describe 或已返回的玩家回调。每次 restore 的实例仍有新身份，未提交接受事务保留最初请求身份，直至 PolicyRouter 对应提案正式提交。新宿主绑定只服务尚未交付的后续事件/请求。

稳定事件 IO 另保存私有交付进度：按原事件索引和接收玩家记录已投影的包、可见索引及交付确认。PolicyRouter 的本地事件接收先同步写入待提交 packets，再返回确认；取消若在此期间发生，宿主先接收该确认，避免把已经接收的事件再次投递。冷恢复直接载入派生数据与交付进度，已确认包保留历史实例身份并跳过回调；尚未交付的包改用新实例身份，保持原调用和可见索引。不可见事件也保留投影完成记录。此标记仅适用于已知同步保存回执的本地处理器，不承诺任意外部异步回调副作用可恢复；公共 Instance 保存边界不变，相关改动未正式验证。

私有 ExecutionSuspended 仅从原执行器已提交的指令边界传出，不成为公共 IO 或 fault。实验把取消、墙钟及内存压力映射为该暂停；已提交但导出失败也保存当前 publication 阶段，不以异常文本猜测能否重新执行。该信号贯穿 Controller 和 GameHost，保留事务而不清空；原子操作尚未提交时的异常不能据此宣称可恢复。暂停后公共游戏操作保持 busy，私有保存按所有权锁定现场，写失败复用同一快照身份与字节；恢复/转移/关闭不能与写盘并行。普通公共 persistence.restore 拒绝私有中途快照。

实验中途检查点先持久化原指令现场和 Controller，再将其引用、GameHost 事务、PolicyRouter 待提交提案/事件及搜索工作一起写入同一原子检查点。成功写入前不释放现场、不提交动作、不增加已完成逻辑步骤；恢复首轮先继续已消费的原边，再按原 prepare/commit 提交接受结果，不重新准备该提案。原执行硬退出且没有对应检查点仍报告现场丢失，不能回到旧检查点重新执行。上述生产接线及逐片冷恢复、事件续接、发布/写盘失败回归已编辑但尚未运行，不能作为恢复验收通过的证据。

共享策略包已删除旧有界 search、SearchBudget 和 R0/R1/R2 接口；STS 删除旧具体未来直推、有限粒子适配器、混合叶子估分与整局搜索额度辅助。成本通过独立 SearchAccounting 记录根获取、恢复、投影、展开、证据和清理，失败工作同样计费；它不承担搜索限制。嵌套阶段耗时不能相加当总耗时，RSS 是计量边界观察到的峰值。加载器已删除历史后验跟踪及随 Instance 保存的搜索额度，Card 执行器和规则绑定已删除前向捕获入口与捕获额度字段。旧有限 ProbabilityFrontier/nextProbability/条件采样、generateProbability、有限分区及样本坐标提交入口均已删除；整数/浮点映射及排序只接精确空间。这些编辑和迁移测试仍待正式检查，不能据删除旧入口声称全部机制或搜索目标已实现。

启动前资源不足时，原尝试保留为未启动状态，允许稍后首次启动；已有 Context 的暂停必须带可恢复检查点。新检查点写成后的旧快照清理失败，不能将新前沿作废或提交成终局。取消发生在提案返回与动作接受之间时，不提交动作、策略记忆或随机游标。重复调度同一未决请求不应累积重复请求包。

宿主的未完成检查点分别保存已提交的 PolicyRouter 状态与私有待提交事务，后者包括已交付事件、请求、已产生提案及其事件游标。保存/恢复只搬运这些数据，不调用 decide、事件归约或随机选择；不能为了保存而执行 prepare(null)，把未提交事件提前混入已提交记忆。冷恢复的首轮继续保存的事务，不能先 begin 清空；正式动作接受后才按原 prepare/commit 路径提交。未提交 packets 只保存在事务内，不能同时追加到已提交前缀。正在等待 decide 的事务不能被视为完整快照或覆盖。稳定 IO 的搜索暂停和真实执行中途暂停均已接入这份待提交事务；后者还组合上方 Controller/GameHost 接受记录，不能丢掉已消费动作再重新请求策略。两条路径的新改动均未正式验证。

检查点持久化失败时，宿主保留原游戏、搜索前沿及已接受记录，只重试快照/检查点写入，不继续 next，也不关闭现场再恢复旧检查点。CLI 报告 persistence-wait、durable:false 和失败阶段。重试以退避让出事件循环，不设重试次数截止；取消请求停止新执行，但仍须等现场保存成功后退出。存储始终不可用时，最新现场仅在存活进程内，不能声称已经落盘。加载器在同一个未变的公共当前状态上重试失败快照时，复用原准备字节及快照身份；已生成游戏快照后的检查点写入失败，也复用该快照。原实际状态变化后不能复用旧准备字节。临时写入失败清理自己的临时文件；终局摘要写入失败只补发已存在的不可变结果，不重新运行游戏。

每段新执行之前，宿主先持久化 active-work 标记，检查点记录相应 workToken。正常保存后标记与检查点一致，可以直接恢复；若重启发现二者不匹配、标记损坏，或第一次开始已写标记却没有检查点，则报告 uncheckpointed-current-lost，保留原尝试为未完成，禁止从旧检查点或 setup 重跑。该保护保守拒绝可能重放的恢复，不等于能找回已经丢失的内存 Context。只有登记了尝试、尚未写执行标记且无检查点的现场，才允许在同一尝试内首次初始化。动作及宿主接受记录提交后即更新下一逻辑步，取消保存不能留下已消费的步号。

在游戏已处于稳定边界时，私有 PolicyWork.prepare 先用真实当前所属的共享 Program 恢复保存的搜索 Context，再允许宿主发布新执行标记。该准备阶段只恢复数据，不调用 decide、不推进规则或搜索边；重复准备不重新恢复已经接管的现场。恢复失败且本段尚无执行时，保留原检查点及原标记并报告 search-restore-failed；若此前刚续行过真实游戏，则先保存该新增现场。真实游戏仍停在已消费指令的续执行边界时，先沿原执行路径续行，不能为了提前准备而公开 fork 一个非稳定游戏。准备耗时计入累计资源和下一次决策的恢复成本。此顺序防止未来的纯恢复崩溃被误标为已开始执行，不能反过来证明旧版本硬退出没有丢失进展。

终局发布成本在现有尝试记录和派生摘要中结算，原 task 文件保持不可变执行证据。publicationMilliseconds 从终局结果产生后开始，包含结果、摘要、计量记录失败的重试等待；冷恢复补发时包含未完成发布期间的停机时间。摘要总毫秒为原执行成本加这段发布成本，每次失败重试重新取样，不把累计值重复相加。最终取样点在最后一次计量记录写出之前，最后一次成功写出本身不递归计入自身。原结果已经落盘而摘要或计量未完成时，启动只读该结果补发；不加载游戏、不初始化或执行动作。已完成且摘要一致时不重复计费。此数据属于原实验尝试记录，不另建验收报告或审计账本。

当前精确搜索与 STS 搜索实验真实执行均已编辑接入原 CardMachine 的可续指令时间片，持久化失败重试、硬退出检测和终局发布计量也已编辑，须由正式检查验证。真实执行指令间的资源暂停保存使用上述私有现场与事务组合；硬退出检测不能恢复丢失的尾部，不能据正常暂停接线宣称任意原子失败或外部副作用均可恢复。共享 replayCard、CLI 重放命令及 --records 隐式重放路径已删除。已发现的 Forge/DDZ/Resolution 动作带差分、通用执行器冷恢复及 Card 基准改为各执行按自身当前请求生成回复；历史结果只比较，不参与候选选择或回复构造。跨进程续行先关闭旧 owner，子进程从快照执行新动作并保存新现场，父进程只恢复新现场。分支隔离检查继续已推进的子分支或使用不同合法动作，不再丢掉子分支后从父状态重做同一条边。基准新增策略/原 contract 计算成本，因此不能与旧动作带驱动测量直接宣称同比收益。源码审阅和定向检索不等于已通过完整无重放审计。

## 验收

全部实现与测试编辑完成后，正式检查局部保血/回合/死亡风险取舍、概率质量、完整支持、信息集决策、估值与经验剪枝标记、精确界限与剪枝、循环、无回退及无重放、父子隔离、概率点及搜索前沿恢复、资源不足保留进度、原规则一致性与生产接线。每项证据对应真实要求，不能用小夹具或旧近似测试证明全局完成。

修正后的生产策略须在原 A20 真实第四幕碎心。所有尝试保留并如实报告，不指定有利未来、不改规则、不把死亡、第三幕胜利或截断当成功；单次胜利不当作可靠胜率。最后审查、同步文档、正式检查、commit、push并核对远端。任何一项未完成，goal 都不得标为完成。


概率合并的候选指纹不得依赖 V8 对 packed/holey 数组的不同编码：运行中新建的权重与冷恢复的同值权重必须能进入同一候选桶。元数据指纹按普通数据图的属性顺序、原型、别名/循环及标量类型构造；摘要仅用于筛选，合并仍由完整元数据、完整当前 Context 与原概率空间相等证明，并精确相加未消费坐标的权重。非普通数据图仍保守放弃该复用，不减少支持。当前 Context 的原始字节候选键尚未改动；不得把这一处元数据修正宣称为全部等价归并或整场搜索完成。


只读位置投影可以从完整压缩 Context 解码原 stop 并按原发布规则导出数据，不必重建可写执行索引；它必须是显式的被动投影入口。Context 内不可变对象的解码副本不得用作原对象身份或执行回复，普通 inspect、动作回复与 next(current) 仍激活原所属图；自定义 project 保留原路径。概率转移缓存若紧接原执行，只压缩缓存自有分支，保留本次执行 owner 的活动图；尚待后续调度的后继仍压缩，避免每个概率律驻留活动图。两项优化只改变表示与纯读取成本，完整保存、外部身份锚、相等证明、概率质量及原操作提交顺序不变。

局部场面估值还计入已安装 Evolve 与公开状态牌的运转协同：按原能力层数和原卡牌类型读取，忽略牌序与消耗区，使用有界、饱和的战略偏好。它不是未来抽牌数量或结算收益的预测；实际抽牌继续执行原能力反应，死亡与终局值不由此覆盖。

定向攻击完全同分时，局部偏好使用目标当前公开生命的 1/(1+HP) 优先集中攻击伤敌。此偏好只在原 estimate、确认死亡/循环、即时估值及上界比较均相同后生效；不计算伤害、不推演敌人结算、不删除候选，也不是严格支配证明。

已生效的敌人正力量作为持续威胁单独扣分，每点权重为 0.012；当前攻击暴露仍来自原意图。该项只表达局部战略偏好，不推导未来招式、触发或伤害，不能当作真实损失或可采纳界限。

局部根动作分组中的任务按稳定节点/动作位置服务：优先让一个未完成后继到达公开决策，再换下一个，避免所有连续出牌后继都只有碎片进展。全局 FIFO 与有限优先突发仍独立执行，组头即使永不完成也不能删除或永久阻塞同组其他工作；冷恢复从保存节点和动作顺序重建相同分组顺序，不重放。
