## 不应据此直接修改的差异

- 无法打出的诅咒：Java费用-2与本库-3属于内部哨兵，是否可打出由资格规则决定；仅数字不同不能断言行为不同。
- 本库14个明确报未实现的异职业/生成牌原型与角色球/姿态体系属于范围缺口，不以无操作冒充实现；本次不新增职业。
- SmokeBomb规则书主要抽到了VFX，遗漏逃跑标志/房间状态赋值及使用资格，不能因缺少语义记录推断它应当无效果。本库目前无逃跑仍是缺口，需额外真机/源码证据后才能修全。
- engine-rules中BigFish/Cleric的“回满”、MoaiHead的“减10”等来自单一样本；不能推广为任意生命状态下的固定规则。需读事件的具体常量/比例与原始探针上下文。
- 逆向仓库公开披露洗牌顺序、怪物完整时间线、选择输入、整局重放尚未验证。其内核的默认选择与本库显式玩家选择不是行为对照基准。

## 直接修复的 C++ 旧缺陷

除上述7项外，将先前仅在构建副本修正的3项落入真实C++源码：觉醒者Curiosity响应、金币奖励索引、宝箱遗物与蓝钥匙互斥。前序C++修复提交为be72f0f，当前基线为bd1a3dc，均尚未推送；本库参考构建只验证固定提交及干净源码，不再动态改写规则。

- 空遗物池：本库此前直接报池耗尽，C++此前回退后仍访问未初始化的vec。现在两边按普通/商店→罕见→稀有回退；稀有池空返回Circlet，Boss池空返回RedCirclet，并保留前/后取方向。加入两种方向、两种执行模式及C++的独立边界回归。

- C++ replaceRelic误查替换后ID：持有位已换，遗物向量却仍为旧ID。改查旧ID，移除Forgotten Altar测试中为旧参考错误设置的特殊比较修补。
- C++ GameAction药水执行后未返回，继续处理奖励/事件界面。补return并删除参考桥药水绕过；测试直接调用GameAction，检查没有误领奖励或执行其他选项。

## 六遗物接入时修正的 C++ 容器及续接缺陷

星系仪叠加原有卡牌奖励可超过5组，将卡牌奖励数组改为可增长容器；同时移除删除最后一组时的越界读取。领取遗物时先删除原奖励，再执行获得效果，避免新奖励被误删。多利之镜从奖励界面打开选牌后，恢复原奖励界面及其后续离开动作，不丢失剩余金币与卡牌。上述变更均在真实C++源码，本次固定到本地提交cd3cdec，未推送。

蠕动肉块的TS获得立即走永久牌组规则。C++保留其战斗上下文与冒险上下文分离的既有结构：植入时结算御守与获得效果，退出战斗时提交永久牌组；定向检查要求两边生命、金币、御守余量及最终牌组一致且不重复结算。战斗中的冒险发布仍是既有入战快照，实际牌组归属通过拥有者查询检查，不用发布快照反推是否已获得。
