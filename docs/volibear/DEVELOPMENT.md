# S2-3.0 · S2_BUFF_D4 实现契约

来源：用户于2026-10-28提供的定稿。完整178个牌面见 [CARDS.md](CARDS.md) 和 [cards_s2.json](cards_s2.json)。此目录记录需求，不作为第二套卡面解释器；实际效果由 `examples/sts/src/content/characters/volibear` 的组合式定义执行。

## 核心机制与关键词

| 关键词 | 定义 |
|---|---|
| 雷势 | 角色独立增幅，每点使每段雷伤增加1，持续本战，不自动消耗。 |
| 雷伤 | 加当前雷势及适用增幅。每段完整结算计1次，全体雷伤同样计1次。 |
| 雷法 | 牌面直接造成雷伤的技能；资格由实际雷伤效果组合声明。 |
| 领域N | 展开或延长N轮，提供攻击附雷、敌方正面特效压制与抽牌净化。 |
| 迎战 | 沿用出牌目标，自动令敌人执行本轮尚余行动。 |
| 吸收 | 本牌迎战期间，以格挡吸收的伤害总量；坚甲时仍按吸收量计算。 |
| 兽化 | 攻击变裂骨之爪，其他牌变风暴之躯，继承材料升级。 |
| 检索／回收 | 分别从抽牌堆／弃牌堆选择指定牌加入手牌，先占用手牌位置。 |
| 减费N | 指定牌本回合下次打出费用降低N。 |
| 咬痕 | 暴怒撕咬留下的敌人标记，按玩家与敌人实体保存，持续本战。强化撕咬读取出牌前标记。 |
| 反雷N | 本轮每承受一段敌人攻击后，对攻击者造成N雷伤，完全格挡也触发。 |
| 蓄势N | 下次打出的每段固定攻击伤害＋N，完整结算后清除。 |
| 强化N | 该牌本战每段自身攻击伤害与原生雷伤＋N。 |
| 重演 | 额外结算一次完整牌效，不是再次打出。 |
| 汲取 | 按该段实际造成的生命损失恢复生命。 |
| 留甲N | 回合开始格挡更新为max(0,当前格挡−N)。 |
| 坚甲 | 承受攻击后格挡保持原值，溢出伤害仍扣生命。 |
| 净化消耗 | 先禁止所选状态或诅咒自身效果，再消耗。 |
| 兽形 | 裂骨之爪、风暴之躯的统称。 |

## 2026-10-28 试玩修订

狂雷渐起改为逐段联动，部署时6／9全体雷伤不变，每段普通攻击结算后造成3／4全体雷伤并叠加雷势。全体普通攻击的一段只触发一次，重演和X费攻击按实际完成段数触发；零段不触发，雷伤本身不递归触发狂雷。领域仍是每次实际出牌一次4雷伤。3／4为用户最新指定数值，尚未完成新版本整局平衡校准；此前2／3试玩属于旧数值样本。U15取消手牌材料的出牌门槛。C21稳住阵脚调整为1／1费、5／8格挡，仍为领域1、抽2张牌。

屹立留甲衰减调整为6／3，费用1／1与入场格挡8／12不变；雷甲每次雷伤获得的格挡调整为3／4，费用1／1与入场格挡4／7不变。此轮改善防御过渡，尚未完成整局平衡验证。

## 统一结算

- 雷势来源只有C25（1／2）、U29（2／3）、U26（每实例每回合第2张真实攻击时1／2）、U04（每实例每回合首次迎战后1）、R28（每实例每回合首次实际打出兽形前1）、R17（支付X／X＋1）。U26按具体升级牌面2处理汇总表冲突。
- 领域基础附雷固定4。每张实际攻击在领域内首次普通攻击段结算后，对全体造成4＋当前雷势的雷伤；多段与重演共用一次机会。
- 领域仅压制对敌人有利的特殊效果，包括复活、保护性阶段、限伤、限牌、无敌、不可选、卡牌改写和取消升级；只保留普通攻击、当前及直接力量、当前及直接格挡，以及必要战斗事实和清理。由被动能力产生的力量和格挡不是直接行动。敌人自身的不利效果继续生效：虚弱、易伤、缓慢增伤、瞬态受伤减攻与到期消逝、飞行层数损失/眩晕、多层护甲损耗。混合能力逐项判断，保留不利部分：守护者受伤计数、转防打断原行动及后续轮次重建阈值保留，转换附带的20被动格挡和尖刺外壳压制；敌人施加给玩家的负面效果仍属于敌方有利效果，继续压制；状态到期清理照常执行。
- 领域1覆盖当前玩家回合、敌方阶段及下一次正常起手抽牌；正常起手抽牌结束先扣1轮，再处理R28起手兽化。兽化后抽牌读取更新后的领域状态。永久领域持续本战。
- 实际抽到状态或诅咒时，净化消耗并补抽1张。检索、回收和移动不是抽牌事件。敌源状态效果（如Burn）每次执行都检查来源压制。
- 7张迎战牌：B04、C04、C10、C11、U28、U35、R09。每敌每轮共享一次行动机会，正常敌方阶段跳过已用动作。动作实际开始、玩家存活且战斗继续才算完成迎战。
- 兽化保持原牌实体、升级、临时减费及保留，切换形态数值；已有兽形不重复转换、不再发转换事件。原牌特殊效果被替代，形态用后消耗，战后永久牌组保持原牌。
- 批量兽化先完成取牌，再固定本次手牌集合，逐张转换；R29覆盖集合中全部牌并减费1，转换响应抽到的新牌不进入本批。
- 手牌上限10。带“至多”的选择从0开始，其他效果按合法目标数量执行。C13和U15均先消耗另一张手牌再抽牌；没有材料时跳过消耗，仍可打出并正常抽牌。消耗是牌效而非前置成本，有材料时仍需选择。
- “此前”读取本次出牌开始的记录；雷伤次数逐段更新。U26第2张攻击力量、雷势和R28首次兽形雷势在支付后、牌效前获得。
- 每次实际出牌计一次；重演沿用目标、已支付X和出牌前条件。原生雷伤逐段结算；每次完整重演执行牌面资源授予。
- 数字费用在固定减费后最低0；同类待用减费取最大值，R14按目标连锁累加。X牌支付当前全部能量，R17有效X=支付X＋升级增幅，同时决定获得雷势与雷击次数。
- 能力持续本战。C17临时力量在玩家回合结束回收；U12增幅覆盖随后敌方阶段；U10强化等待可跨回合。
- 返能不再设置每回合一次限制。C26、U40每次牌效满足出牌前雷伤条件均返能，多张与重复结算不共享额度。U21各部署实例在本回合第2、4、6…次雷伤后各返1能量；部署时本回合已有至少2次雷伤立即返1，不补发此前所有次数，随后照常响应后续偶数次雷伤，计数不跨回合。R30每次实际打出躯形返1能量，爪形格挡仍限每回合首次。
- 咬痕由实际攻击命中登记，完全格挡及致死均成立；随敌人实体保存。同次重演不读取刚施加的标记。U08对已有标记目标在该次普通攻击段中追加伤害。
- 普通格挡受敏捷、脆弱影响；R05直接将现有格挡乘3。坚甲不改变回合开始的默认清除／留甲规则。以力量计算附加效果时读取正力量。
- 展开领域时取消待复活；生命为零且没有敌对实体时立即满足胜利。取消的一次性复活、阶段、改写事件已消费，离开领域后不得补发。

## 实现入口

生产卡池由 `examples/sts/src/content/characters/volibear/catalog.ts` 的 `byCode` 绑定真实规则定义，奖励池排除4张基础牌和2张兽形。各牌效果在 `cards/`，雷势、领域、迎战、兽化和费用状态在 `mechanics/`，按部署实例计次的能力在 `powers/s2.ts`。

兽化通过战斗牌的行为定义引用切换形态，材料实体与永久主牌引用不变；每实例计数、咬痕、固定兽化集合和选牌续执行都保存在原有 Context。共享规则只扩展牌行为查询和效果来源门控，不增加公共动作协议，也不引入另一套执行器。`cards_s2.json` 与 `implementation_spec.json` 是可阅读的契约记录；游戏仍直接执行同一份组合规则，运行时牌面说明由该规则组合生成。

基础设置仍为80／80和10张初始牌。现有STS升阶规则继续适用：A20最大生命75、初始生命68；本次未重做其他角色、完整尖塔2敌人库或五角色规划器。
