# 简化协议实施验收

用户范围：按三层纵轴和功能横轴收敛公共协议；动作只包含动作，时间/超时属于独立可选会话控制；同步实际斗地主及全部有效消费者、文档和证据。

| 项目 | 期望证据 |
| --- | --- |
| 三层依赖 | Core/Instance 不依赖 Game；基础运行与可选保存、分支、捕捉分别导出；依赖审计 |
| 请求收敛 | 请求直接声明 player；统一请求身份；onRequest；无 actor 映射和多层 choice/offer 包装 |
| 动作边界 | 动作类型及 exact 列表不含交付时间；describe/validate 与相同动作类型对应；超时由独立会话控制输入 |
| 单步 | Instance 一次最多接受一个端口返回；Game 一次最多接受一个动作或会话控制，交付后续事件后停止；无次数限制/计数字段 |
| 接受反馈 | 返回具体请求、玩家、动作，或会话控制输入；后续暂停、取消、故障仍保留已接受事实 |
| 并发 | 游戏保存部分输入并发布剩余请求；驱动只保证一次接受，不决定同时选择的游戏结果 |
| 基本运行 | 无保存/分支/捕捉能力仍能接线、运行和结束 |
| 可选能力 | 保存、分支、捕捉分路径导出，父子为同类型；原有生命周期与故障行为明确 |
| 游戏迁移 | 完整斗地主动作对局、纯会话超时、同时加倍、私密事件、非法/过期/错玩家拒绝；独立牌型 oracle 保留 |
| 原生消费者 | 使用公开作者约定和 IO；验证新协议实际可接线与单步接受反馈 |
| 清理 | 公共类型、包导出、消费者和有效文档没有旧协议混合或兼容入口；辅助类型移出基础入口 |
| 交付 | npm run check；迁移审计；check_project 与负向自检；源码/证据哈希；提交推送 |

当前为 C01 协议与真实游戏作者/原生消费者实施。C02/C03 提供生产受控执行、完整续延保存及正式绑定器。
